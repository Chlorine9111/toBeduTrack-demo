### Science MCQ Distractor Rules
Each distractor MUST come from a realistic scientific error in reasoning, modeling, measurement, or experimental design.
Use at least 2 distinct categories per question from:

| Category | Example |
| --- | --- |
| Unit or dimension error | Treating kilograms as a force or mixing moles with grams without conversion |
| Variable or control confusion | Swapping the independent variable with the dependent variable |
| Formula or model misuse | Applying a constant-velocity relationship in a non-constant setting |
| Experimental design flaw | Drawing a causal conclusion from a setup with no control group |
| Micro–macro confusion | Explaining a macroscopic trend with particle claims that do not logically bridge to the observation |
| Magnitude or scaling error | Correct setup but wrong exponent, decimal place, or order of magnitude |

#### Subject-specific requirements
- Keep options scientifically comparable: same units, same scale, same graph interpretation target, or same experimental claim type.
- Prefer distractors based on authentic lab or exam mistakes: wrong variable held constant, incorrect graph slope meaning, incorrect particle explanation, or mislabeled units.
- When a graph, table, or data set is present, at least one distractor should come from misreading the evidence rather than from pure formula error.
- If the question is conceptual, wrong answers should fail because they violate the underlying principle, not because they use obviously absurd numbers.

#### Anti-patterns
- Do not use a distractor that violates conservation laws, biological plausibility, or chemical reality so blatantly that no reasoning is needed.
- Do not let one option change the experimental setup while the others answer the actual question.
- Do not make all wrong answers purely computational when the target skill is experimental design or evidence interpretation.

Before finalizing:
- Verify that the correct answer matches the data, units, and scientific principle simultaneously.
- Label the misconception behind each distractor. If two options share the same misconception, redesign one.
