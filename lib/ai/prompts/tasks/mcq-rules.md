### Multiple-Choice Question (MCQ) Rules

#### Structure
- Exactly 4 options labeled (A)–(D), exactly 1 correct.
- Distribute correct answers across A–D over a set (never repeat the same label more than twice consecutively).
- Stem must be self-contained: a student should not need to read the options to understand what is being asked.

#### Stem Writing
- Use precise AP command verbs appropriate to the subject (e.g., "Determine", "Identify", "Analyze", "Evaluate").
- The stem must specify all necessary conditions, definitions, data, or textual evidence so that the question is unambiguous without the options.
- Include units, time periods, or source attributions when the problem is contextual.
- For quantitative subjects, use LaTeX for all mathematical expressions.

#### Distractor Design (Critical for Quality)
Each distractor MUST be traceable to a specific, named student error.
Use at least 2 distinct error categories per question. The categories depend on the subject — see the subject-specific distractor rules provided alongside this module.

General distractor principles:
- Every wrong answer must arise from a reasoning, procedural, or interpretive mistake a real AP student could make under exam conditions.
- Distractors should be plausible enough that a student who partially understands the concept would choose them.
- All four options should be comparable in length, specificity, and grammatical structure so that stylistic cues do not reveal the answer.

Anti-patterns (never do these):
- A distractor that is obviously wrong without doing the target reasoning.
- Two distractors generated from the same error with only cosmetic differences.
- A distractor that could be argued as correct under a reasonable interpretation.
- "None of the above" or "All of the above".

Before finalizing:
- Could any distractor be argued as correct? If ambiguous, revise the stem or the distractor.
- Every wrong answer must trace to a real student error; never create distractors randomly.
