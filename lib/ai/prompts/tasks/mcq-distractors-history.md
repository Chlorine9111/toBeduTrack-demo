### History MCQ Distractor Rules
Each distractor MUST reflect a realistic historical reasoning error, not random factual noise.
Use at least 2 distinct categories per question from:

| Category | Example |
| --- | --- |
| Chronology error | Attributing a postwar development to an earlier prewar policy context |
| Causation reversal | Treating an effect as the cause of the historical change |
| Similar event or policy confusion | Mixing up the Monroe Doctrine and the Roosevelt Corollary |
| Overgeneralization | Turning a partial trend into a universal claim about all groups or regions |
| Source misreading | Taking irony, bias, or rhetorical framing as literal author belief |
| Perspective collapse | Explaining the event only from one group's viewpoint while ignoring the actor named in the prompt |

#### Subject-specific requirements
- Keep all options inside the same broad time period, region, and topic frame so the student must reason historically rather than eliminate obvious outsiders.
- Distractors should differ in historical interpretation, causal logic, or evidence use, not just in wording strength.
- For stimulus-based questions, every option should be plausible to a student who partially understands the document but misses context, audience, purpose, or historical situation.
- Wrong answers should usually contain a grain of truth attached to the wrong claim, timeframe, or causal link.

#### Anti-patterns
- Do not use an option that is wrong only because it names a completely unrelated century or region.
- Do not make the correct answer stand out by being the only option with specific evidence.
- Do not reward pure memorization when the stem is clearly designed to test sourcing, comparison, continuity/change, or causation.

Before finalizing:
- Check that the correct option is supported by both the historical context and the prompt's specific evidence.
- Ask whether a strong student could defend a wrong option with reasonable evidence. If yes, sharpen the stem or revise the option.
