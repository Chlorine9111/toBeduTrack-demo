### Science FRQ Scoring Notes
Use AP-style scoring that rewards correct scientific setup, evidence-based reasoning, and disciplined treatment of variables, units, and limitations.

#### Point design
- Separate points should reflect distinct scientific acts: identifying the principle or hypothesis, setting up the model or experiment, using data correctly, and drawing a justified conclusion.
- Award calculation points separately from conceptual explanation when the problem contains both.
- Award experimental-design points only when the student specifies variables, controls, measurements, or procedures clearly enough to be testable.
- Award conclusion points only when the claim is linked to evidence, not merely asserted.

#### Common scoreable acts
| Skill | What earns the point |
| --- | --- |
| Principle or model selection | Chooses the correct law, mechanism, pathway, or scientific relationship for the scenario |
| Data or quantitative setup | Uses the correct equation, graph reading, table values, stoichiometric ratio, or statistical summary |
| Variable control | Correctly identifies independent, dependent, and controlled variables or comparison groups |
| Evidence-based reasoning | Connects observations, trends, or calculations to the scientific claim using domain logic |
| Evaluation or limitation | Notes uncertainty, error source, confounding factor, or design limitation when the prompt asks for critique |

#### Partial-credit guidance
- Give setup credit when the student selects the right formula, graph relationship, or experimental comparison even if later arithmetic slips occur.
- Allow follow-through credit when a later explanation is consistent with the student's earlier nonfatal error.
- Distinguish between reading the data correctly and explaining what the data mean scientifically.
- Require units, labels, or variable names when the response would otherwise be ambiguous.

#### No-credit patterns
- No credit for conclusions that ignore contradictory data or omit the supporting trend.
- No credit for experimental claims with no control condition, comparison basis, or measurable outcome when those are required by the prompt.
- No credit for explanations that simply restate the observation without invoking the relevant scientific principle.
- No credit for calculations with missing or incompatible units when unit consistency is part of the reasoning.

Before finalizing:
- Ensure each point is attached to evidence a scorer could actually see in student work.
- Ensure the rubric distinguishes scientific reasoning, data use, and procedure quality instead of treating them as one broad category.
