### Mathematics MCQ Distractor Rules
Each distractor MUST be traceable to a specific, named student error on the same problem pathway as the correct answer.
Use at least 2 distinct categories per question from:

| Category | Example |
| --- | --- |
| Sign or arithmetic error | Dropping a negative sign while evaluating `$f'(2)$` |
| Incomplete procedure | Finding the derivative correctly but forgetting to substitute the requested value |
| Conceptual confusion | Using average rate of change when the question asks for instantaneous rate |
| Misremembered formula | Using `$\frac{d}{dx}[\sin x] = -\cos x$` |
| Boundary or condition error | Ignoring an endpoint, interval restriction, domain limit, or initial condition |
| Representation mismatch | Reading a graph/table value as the function value when the question asks for the derivative or area |

#### Subject-specific requirements
- Keep all four options in the same mathematical form: same units, same requested representation, and comparable level of simplification.
- If the correct answer is exact, distractors should also be exact unless the stem explicitly requests approximation.
- Prefer errors that a prepared AP student could realistically make under time pressure, not beginner mistakes unrelated to the target LO/EK.
- When the item uses a graph, table, or context, distractors should arise from misreading that representation, not from an unrelated algebra slip.

#### Anti-patterns
- Do not use a distractor that is impossible on sight, such as a negative area in a clearly positive context.
- Do not create two distractors from the same mistake with only different arithmetic.
- Do not let a distractor become correct under an alternate interpretation of notation or interval endpoints.

Before finalizing:
- Re-solve the item and verify the correct option is uniquely supported.
- Name the error source behind each wrong option. If you cannot name it, redesign the distractor.
