### 学科适配：自然科学（AP Physics / AP Chemistry / AP Biology）

以下规则覆盖物理、化学、生物等实验科学，在通用 Block 质量要求基础上追加执行。

**example block**
- 物理/化学计算题：必须包含具体数值和单位（如"m = 2.0 kg, a = 3.0 m/s²"），steps 是"画受力图/写方程 → 选择公式 → 代入数据（保留单位）→ 计算结果 → 合理性检验"。
- 生物分析题：以具体实验数据或现象为起点，steps 是"观察描述 → 提出假设 → 设计对照实验 → 分析数据趋势 → 得出结论并讨论局限"。
- 最后一步必须包含误差来源讨论或结果合理性检验。
- 禁止输出“纯数学练习题”作为科学教案的例题：不得出现只围绕 `f(x)`、`h(x)`、`p'(5)`、Chain Rule 等纯求导/纯代数化简的题干与步骤。
- 若需要使用微积分（AP Physics C 允许），必须绑定物理语境与物理量：例如 `W=\\int \\vec F\\cdot d\\vec r`、`P=dW/dt`、`F=-dU/dx`，并明确变量含义与单位；不得把“推导/例题”退化成函数求导套路题。

**paragraph block**
- Teacher: 演示具体实验 / 展示数据图表（折线图、柱状图） / 播放现象视频并暂停提问。
- Student: 先预测实验结果再观察 / 记录数据到表格 / 分析自变量与因变量的关系。
- 必须说明具体演示什么实验、测量什么物理量、用什么仪器。

**definition block**
- 三层结构：① 科学定义（含符号、单位、化学式或生物学术语）② 物理意义或生物功能的直觉解释 ③ 日常生活中的应用示例。
- 化学定义需包含微观解释（分子层面发生了什么）。
- 生物定义需包含功能解释（对生物体有什么意义）。

**quiz block**
- 优先使用实验场景或数据图表作为题干。
- 考查变量控制（哪个是自变量/因变量/控制变量）、实验设计改进、或数据趋势推理。
- explanation 必须用科学原理解释，而非仅描述正确答案。

**关键原则**
科学教案的"具体"= 有实验、有数据（含单位）、有现象描述、有变量分析。不能脱离实验和数据空谈理论。
