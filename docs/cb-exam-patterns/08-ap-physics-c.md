## 二、MCQ 分析

### 2.1 题干结构分类

通过分析 Practice Exam 和 Question Bank U3，我识别出以下主要题干模式：

**模式A：图形-推理型（约35%）**
- 给出实验装置图、运动轨迹图、力图或图表
- 要求学生从图形中提取信息并推理
- 典型例子：第2题（位置时间图推v-t图+配对推理说明）；第3题（角速度图比较角位移）；第5题（参考系转换——不同观察者看到的轨迹）

**模式B：直接计算型（约25%）**
- 给出数值条件，要求计算具体结果
- 微积分的应用是关键区分点：W = ∫F·dx, U = -dU/dx 等
- 典型例子：U3第10题（F=kx^3, 求W = ∫kx^3 dx）；第11题（给出力和角度求KE变化）；第12题（非线性弹簧 F=40x-6x^2 求PE变化）

**模式C：概念辨析型（约25%）**
- 无需计算，考查物理概念深度理解
- 常用"which of the following correctly..."句式
- 典型例子：第1题（力-位置图→势能变化趋势）；第7题（SHM条件的justification）；第15题（力与速度平行→KE增加）

**模式D：多表征翻译型（约15%）**
- 在多种表征（图形+文字+公式+推理）之间转换
- 典型例子：第2题（位置图→v-t图+文字推理，4个选项各含图+文字配对）
- 这是AP物理C的特色题型，AP物理1很少出现

### 2.2 选项设计与干扰项手法

**手法1：维度/量纲陷阱**
- 提供多个选项，仅在指数、系数或根号上有差异
- 例如 U3第20题：F=kx^2, 求功 → 选项含 kx_0^3, kx_0/2, kx_0^3/2, kx_0^2/3, kx_0^3/3（正确答案需要积分）
- 干扰项来自：忘记积分直接用F*x（得kx^3）、积分时指数错误

**手法2：物理直觉陷阱**
- 利用学生的"常识性"直觉制造错误
- 第10题（两石头从同一高度以相同速率分别向下和水平抛出）：直觉认为竖直下抛更快到达且速度更大，但正确答案是同时到达且速度相同（能量守恒）
- 第17题（两个不同形状的轨道，同一高度出发）：直觉认为路径短的滑得远，但能量守恒给出d1=d2

**手法3：图-图配对选择**
- 每个选项包含一个图形+一段文字推理
- 考生必须同时判断图形正确性和推理正确性
- 这是2025新考纲的特色，大幅增加了难度

**手法4：比例关系变形**
- 改变系统参数后求新的物理量
- Practice Exam第8题：转动惯量加倍→杆长变为原来的几倍？选项: l/2, l/sqrt(2), sqrt(2)*l, 2l
- 第9题：三球万有引力叠加计算

**手法5：符号/方向陷阱**
- 涉及功、势能的正负号
- U3第6题：正方向做功100J，摩擦耗散40J → KE变化 = 60J（陷阱：0J, 40J, 100J, 140J）

### 2.3 微积分在力学MCQ中的应用方式

| 微积分操作 | 题目数量占比 | 典型形式 |
|---------|----------|--------|
| 定积分求功 W = ∫F dx | ~20% | F=kx^n 形式，非线性力 |
| 导数求力 F = -dU/dx | ~10% | 给U(r)求F(r) |
| 图形下面积 | ~15% | v-t图→位移，F-x图→功 |
| 微分方程识别 | ~5% | SHM的判定条件 |

**关键区别于AP物理1**：AP物理1从不要求积分或微分运算。AP物理C力学的MCQ中约30-40%的题目需要微积分操作，这是最核心的难度提升。

### 2.4 与AP物理1的难度差异

| 维度 | AP物理1 | AP物理C力学 |
|------|--------|----------|
| 选项数 | 4个(A-D) | 4个(A-D)（新考纲），部分题库仍5个 |
| 数学工具 | 代数+三角 | 微积分+矢量分析 |
| 推理层级 | 单步推理为主 | 多步推理+数学推导 |
| 图形复杂度 | 单一图形 | 多图配对、分区域图 |
| 物理模型 | 质点、理想弹簧 | 非均匀分布、变力、转动惯量积分 |
| 概念深度 | "what happens" | "why + derive expression" |

## 三、FRQ 分析

### 3.1 题目结构与分类

2025年考纲的FRQ固定为4种题型：

| 题号 | 题型名称 | 分值 | 建议时间 |
|------|--------|------|---------|
| Q1 | Mathematical Routines（数学程序） | 10分 | 25min |
| Q2 | Translating Between Representations（表征转换） | 12分 | 30min |
| Q3 | Experimental Design（实验设计） | 10分 | 25min |
| Q4 | Qualitative/Quantitative Translation（定性定量转换） | 8分 | 20min |

### 3.2 各题型的出题模式

**Q1 Mathematical Routines（数学程序题）**
- 核心特征：给出一个复杂物理情境，要求通过微积分完成多步推导和计算
- Practice Exam Q1：盘和轮的摩擦力 F_f = Ae^{-Bt}
  - (a)i. **Calculate** 角动量 → 需要 ΔL = ∫τ dt = ∫(Ae^{-Bt})R_0 dt（指数函数的积分）
  - (a)ii. **Justify** 角动量变化不等 → 需要比较力矩臂不同
  - (b) **Derive** 角速度表达式 → 角动量守恒 + 平行轴定理

- 评分模式：每个关键步骤1分，包括：
  - 写出正确的物理原理/公式（1分）
  - 正确建立积分表达式（1分）
  - 正确执行积分（1分）
  - 正确代入数值得到答案（1分）
  - 正确单位（1分）

**Q2 Translating Between Representations（表征转换题）**
- 核心特征：在自由体图、公式推导、图形绘制、文字解释之间转换
- Practice Exam Q2：弹簧+双滑块系统
  - (a) **Draw and label** 自由体图（2个物体各1个）
  - (b) **Derive** t_4的表达式 → 需要识别周期变化（2m→m）
  - (c) **Sketch** v-t图 → 需要理解SHM曲线特征
  - (d) **Indicate and Justify** t_4的位置
- 特色：同一题目融合了绘图+推导+作图+文字论证四种能力

**Q3 Experimental Design（实验设计题）**
- 核心特征：设计实验、线性化数据、画图、从图中求物理量
- Practice Exam Q3：F_D = bx^n（非线性恢复力）
  - (a) **Describe** 实验步骤
  - (b) **Identify** 线性化坐标轴（log F vs log x）→ 斜率=n, 截距=log b
  - (c) 给数据表 F_S = kx^{1/2} → **Plot** 并**Draw** 最佳拟合线
  - (d) **Calculate** k值

- 关键手法：**对数线性化**是电磁学和力学共通的核心实验技能
  - F = bx^n → log F = n log x + log b
  - F = kx^{1/2} → 画 F vs x^{1/2}

**Q4 Qualitative/Quantitative Translation（定性定量转换题）**
- 核心特征：先定性分析物理趋势，再推导数学表达式验证
- Practice Exam Q4：链条被电机拉上桌
  - (a) **Justify** 摩擦耗散功率是增还是减（定性）
  - (b) **Derive** 摩擦耗散总能量 → ΔE = ∫μ_k (M_c/L_c)(x_0 - x) g dx（变质量积分）
  - (c) **Describe and Justify** 电机功率变化

### 3.3 FRQ 动词指令系统

| 动词 | 含义 | 评分要求 |
|------|------|---------|
| **Calculate** | 数值计算 | 必须给出数值+单位 |
| **Derive** | 推导表达式 | 必须从基本原理出发，展示完整步骤 |
| **Justify** | 论证 | 必须用物理原理支撑结论 |
| **Describe** | 描述 | 文字说明物理过程 |
| **Sketch** | 画草图 | 定性正确的图形 |
| **Draw and Label** | 精确绘图 | 自由体图等必须标注 |
| **Indicate** | 指出 | 在图上标记 |

### 3.4 评分模式特点

从评分标准中提取的关键模式：

1. **"1 point per brick"（逐步给分）**：每个关键逻辑步骤独立1分，前后步骤不影响
2. **Alternate Solutions（替代解法）**：CB明确列出多种合法解法并给相同分数
3. **Unit Point（单位分）**：通常有1分专门给正确单位，且"在任意2个答案中给出正确单位且无错误单位"即可
4. **Scoring Note（评分说明）**：允许灵活性，如"不简化的表达式也可得分"
5. **Carry-through Credit（连贯分）**：前面错误不影响后续步骤的得分

|------|------|
| 考试时长 | 3小时（MCQ 1h20min + FRQ 1h40min） |
| MCQ | 40题（部分题库仍为5选项），占总分50% |
| FRQ | 4题（预计），占总分50% |

## 二、MCQ 分析

### 2.1 题干结构分类

通过分析 U8（静电学/库仑定律）和 U9（电势/电容），识别出以下模式：

**模式A：电荷构型分析型（约30%）**
- 给出2-4个点电荷/带电体的空间排列图
- 要求分析力、电场、电势
- 大量使用对称性和矢量叠加
- U8第1题（半环正负电荷→中心电场方向）；第6-8题（三电荷A,B,C共线平衡）；第9题（正方形四角电荷→力的方向）

**模式B：平行板/电容器型（约15%）**
- 带电粒子在均匀电场中运动
- U8第5题（负电荷在平行板间→x(t)和y(t)图像选择，5个选项各含2个图形）
- U9第2题（增大板间距→E和V的变化）；第4题（两区域不同E→粒子运动距离）

**模式C：等势线/电场图分析型（约20%）**
- 给出等势线图，要求判断E的大小、方向、做功
- U9第6-9题（等势线集合题）：
  - Q6: 正电荷沿等势线移动→做功=0
  - Q7-8: 不同路径做功的正负
  - Q9: 等势线形状→反推电荷分布
  - Q16: 等势线间距密→E大
  - Q17: W_ext = qΔV 的数值计算

**模式D：定性/半定量推理型（约20%）**
- 不需精确计算，考查物理图像
- U8第2题（负导体吸引第二个物体→可能是I/II/III？）
- U8第13题（三球互相接近→观测吸引/排斥→预测第三对行为）
- U8第14题（三电荷释放→运动方向和加速度变化）
- U8第15题（导体球Y靠近带电球X→感应电荷→力和势能变化）

**模式E：库仑力比例计算型（约15%）**
- 标准化的比例推理题
- U8第3题（加入第三个电荷使力减半→q=?）
- U8第10题（电荷翻倍、距离变→力变?）
- U8第11题（2Q*3Q vs 2Q*9Q，距离加倍→力比）

### 2.2 选项设计与干扰项手法

**手法1：矢量方向陷阱**
- 电场和力的方向判断
- U8第1题：半环上下分别+q和-q → 对中心电子的净力方向
  - 陷阱：混淆"电子受力"与"正电荷受力"方向
  - 陷阱：忽略对称性导致分量抵消

**手法2：标量vs矢量混淆**
- 电势是标量叠加（不分方向），电场是矢量叠加
- U9第5题：V=0的点 ≠ E=0的点
- U9第12题：等势面上两点 V_I vs V_II

**手法3：比例因子陷阱（电磁学特色）**
- 库仑定律中的r^2：改变距离和电荷后的组合效应
- U8第3题：引入q使F减半 → 需联立两个方程
- 选项设置为 Q, Q/2, Q/4, Q/8, Q/16（几何级数陷阱）

**手法4：能量vs力的混淆**
- 力是矢量（可以抵消为零），势能是标量（不抵消）
- U8第15题：导体球Y被吸引（力）但势能可能增加
- U8第16题：W_ext和W_elec的正负号同时判断（表格选择）

**手法5：图形密度陷阱（等势线题）**
- 等势线越密→E越大
- 学生常犯错误：误认为等势线标注的V值越大→E越大

### 2.3 微积分在电磁学MCQ中的应用

与力学相比，电磁学MCQ中的微积分运用更少，主要出现在：

| 操作 | 典型场景 |
|------|--------|
| V = -∫E dr | 从E求V，或从V求E |
| E = -dV/dx | 等势线间距→E的估算 |
| qV = (1/2)mv^2 | 能量守恒（代数为主） |
| 维度分析 | 判断表达式合理性 |

MCQ中微积分的占比约10-15%，远低于FRQ。

### 2.4 题组（Set Questions）的出题模式

电磁学大量使用**共享情境的题组**：

- U8第6-8题：三球A,B,C共线 → 3道连续题考电荷符号、电荷比、电荷A的可能性
- U8第19-20题：等边三角形三电荷 → 力的大小和方向
- U9第6-9题：等势线图 → 做功、方向、电场源
- U9第16-17题：等势线图 → E大小排序、数值做功

这种题组设计让学生必须正确理解第一题的情境才能做后续题目，有效区分了真正理解和猜测。

## 三、FRQ 分析

### 3.1 电磁学FRQ的核心特征

从 U8 FRQ（7道题）和评分标准中提取出以下模式：

**类型1：高斯定律推导型（最高频）**
- Q1：球形电容器（导体球+球壳）→ 分4个区域求E(r)
- Q2：非均匀体电荷密度 ρ(r) = ρ_0(1-r/R) → 求E(r>R), V(r>R), E(r<R)
- Q4：均匀带电圆柱 → Gauss定律求内外E → 再用Ampere定律求B
- Q5：圆柱形电容器（含介质）→ Gauss定律求E → 积分求V → 求C

**共同结构**：
1. 分区域讨论（r<a, a<r<b, b<r<c, r>c）
2. 选择Gauss面 → 写 ∮E·dA = Q_enc/ε_0
3. 对称性化简 → E(4πr^2) = Q_enc/ε_0 或 E(2πrL) = Q_enc/ε_0
4. 可能接着求 ΔV = -∫E dr → C = Q/ΔV

**类型2：连续电荷分布积分型**
- Q3：弧形线电荷密度 λ → 积分求中心处 E 和 V
  - 需要：dE = kλdθ/R, 用对称性消y分量, 积分∫cos θ dθ
  - 难度：对称性判断+正确的积分限+正确的微元

**类型3：电磁结合型**
- Q4：先求静电场（Gauss），再变为导体求磁场（Ampere）
- Q5：电容器→排空介质→接电池→变为载流圆柱→Ampere求B
- 这种"同一几何体先考E后考B"是电磁学FRQ的经典模板

**类型4：实际场景应用型**
- Q7：雷暴云的电荷分布 → 镜像法（地面导体）→ 叠加4个点电荷
  - 求地面点P_1的E → 比较P_2的E → 求电势 → 求电势能
  - 这种题目结合了真实物理场景，但本质仍是点电荷叠加

### 3.2 评分标准的详细模式

**分值分配（以Q1球形电容器为例）**：
- Part (a): 4分 → V=Q/(4πε_0r) 代入 → 求Q（公式1分+代入1分+数值1分+符号1分）
- Part (b): 5分 → 4个区域各1分 + 1分"统一点"（提到enclosed charge或Gauss定律）
- Part (c): 3分 → ΔV = -∫E dr（写积分1分+代入1分+结果1分）
- Part (d): 2分 → C = Q/V 或 C = 4πε_0ab/(b-a)
- Unit point: 1分 → 任意2个答案单位正确

**评分关键特征**：

1. **Alternate Solution 制度**：每道题都明确列出2-3种替代解法。例如Part(c)既可以用积分法，也可以用V=Q/C法（如果先做了Part(d)）。
2. **"1 point for..."的原子化**：每个物理/数学步骤独立赋分，不存在"全对才得分"的模式。
3. **Part间的独立性**：Part(d)可以直接用C=Q/V，即使Part(a)(c)做错了也能通过正确公式得分。
4. **体电荷密度积分的评分**（Q2 Part d）：
   - 1分：写出Q = ∫ρ dV
   - 1分：dV = 4πr^2 dr
   - 1分：代入ρ(r)并积分
   - 这要求学生必须写出微元，不能跳步

### 3.3 电磁学FRQ中的微积分深度

| 微积分操作 | 在FRQ中的角色 | 示例 |
|---------|-----------|------|
| ∮E·dA = Q_enc/ε_0 | Gauss定律（面积分） | Q1,Q2,Q4,Q5 |
| ΔV = -∫E dr | 电场→电势 | Q1(c), Q5(b) |
| ∮B·dl = μ_0 I_enc | Ampere定律（线积分） | Q4(c), Q5(c) |
| Q = ∫ρ(r)4πr^2 dr | 非均匀电荷求总电荷 | Q2(d) |
| dE = kλdθ/r^2 | 连续分布直接积分 | Q3(b) |
| F = -dU/dx | 力-势能关系 | 较少 |

**核心发现**：电磁学FRQ中的微积分密度远高于力学，几乎每道题都需要至少一次显式积分。最典型的模式是 Gauss面/Ampere环 → 化简 → 分段讨论 → 积分求电势/电容。

### 3.4 与AP物理1 FRQ的关键区别

| 维度 | AP物理1 FRQ | AP物理C电磁 FRQ |
|------|-----------|-------------|
| 数学工具 | 代数、比例 | 面积分、线积分、体积分 |
| "Derive"要求 | 从公式出发 | 从第一性原理(Gauss/Ampere)出发 |
| 分区域讨论 | 无 | 核心要求（每个FRQ都有） |
| 实验设计 | 定性描述为主 | 对数线性化、最佳拟合线 |
| 定性分析 | 占较大比重 | 仅Q4部分考查 |
| 图形绘制 | 简单力图 | E(r)图、V(r)图、等势线 |
| 单位分 | 通常不单独考 | 明确的Unit Point |

## 五、两学科共通的出题者策略总结

### 5.1 CB的核心设计哲学

1. **微积分是工具而非目的**：题目从不孤立考查微积分技能，而是要求学生将微积分作为物理推理的自然延伸。例如"为什么功等于F-x图下面积？"而不是"请计算∫sin(x)dx"。

2. **多表征流畅性**：一道好题要求学生在以下表征间无缝切换：文字描述 ↔ 图形 ↔ 公式 ↔ 图表数据。2025新考纲尤其强化了这一点（MCQ中图+推理配对选项）。

3. **"Justify"文化**：不仅要答对，还要解释为什么。这体现在FRQ中大量使用"Justify your answer"，以及MCQ中选项本身包含推理。

4. **分区域思维**：物理C最核心的能力是"知道什么时候用什么规律"。几乎所有FRQ都要求分区域讨论，这是与物理1最大的差异。

### 5.2 出题数据模式

- **每页约1-2道MCQ**，复杂图形题占整页
- **FRQ每题约3-5页**（含大量空白答题区）
- **共享情境题组**在电磁学中比力学更常见
- **数值计算vs符号推导**的比例约为 3:7（符号推导为主）
- **Practice Exam的MCQ第1题永远是中等难度**（让学生建立信心），最难的题在中后段
