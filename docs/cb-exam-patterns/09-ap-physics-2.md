## 二、MCQ 深度分析

### 2.1 题干结构分类（基于40题全卷统计）

| 题干类型 | 占比 | 典型特征 |
|---------|------|---------|
| **图表驱动型** | ~50% | 提供电路图、PV图、力图、电荷分布图、波形图、光路图等，要求从图中提取信息 |
| **概念推理型** | ~25% | 纯文字描述物理情境，考查定性理解和因果推理 |
| **计算型** | ~15% | 给定数值，要求代入公式计算具体结果 |
| **实验数据型** | ~10% | 给出实验数据/图表，考查数据分析和图形斜率含义 |

### 2.2 Stimulus（题目情境）类型分布

| Stimulus 类型 | 出现频次 | 实例 |
|-------------|---------|------|
| **电路图** | 高频(~8题) | 并联/串联电阻、RC电路、内阻电池 |
| **PV图/热力学过程图** | 高频(~4题) | 等温/等容/绝热过程、状态转换 |
| **电荷/电场分布图** | 高频(~5题) | 点电荷体系、带电球体、电场方向 |
| **光学光路图** | 中频(~4题) | 透镜成像、衍射/干涉图样、光线追踪 |
| **磁场区域图** | 中频(~4题) | 磁场中运动导线、导体环、带电粒子运动 |
| **波形图** | 中频(~3题) | 电磁波E-z图、驻波、速度分布 |
| **能级图** | 低频(~2题) | 原子跃迁、光电效应 |
| **核反应方程** | 低频(~2题) | 衰变方程、质量亏损 |
| **实验装置图** | 中频(~3题) | 注射器-活塞、电容器、热传导块 |

**关键发现**：超过70%的MCQ都附带图形/图表，纯文字题不到30%。CB极度重视"从视觉表征中提取和转化信息"的能力。

### 2.3 选项设计与干扰项手法（核心出题术）

通过对答案解析的逐题研究，CB干扰项有以下系统性手法：

#### 手法1：符号/方向反转陷阱（最高频）
- **正确答案**的数值大小正确，但方向（进入/离开页面，正/负）相反
- 例：Q4 磁力题，(A)力大小正确但方向是正电荷的方向；(D)方向正确但漏乘电荷系数

#### 手法2：公式变量混淆陷阱
- 将公式中的两个量颠倒比值关系
- 例：Q1 镜面成像，干扰项将物距/像距在放大率公式中互换
- 例：Q3 电阻率与温度，干扰项误认电流增大（混淆R增大时I的变化）

#### 手法3：表格型"两维判断"陷阱
- 呈现两个物理量变化的表格，让学生同时判断两个量
- 正确答案需要两个判断都对；干扰项通常一个对一个错
- 例：Q3 电流/电阻变化表格、Q5 分子速度/容器力表格、Q35 磁通量大小/符号表格

#### 手法4：图形选择型（视觉干扰）
- 4个选项是4张不同的图，只有一张正确
- 干扰图通常形状相似但关键特征（初始值、渐近线、曲率方向）不同
- 例：Q14 PV图选择、Q21 RC电路电压-时间图、Q25 衍射图样、Q27 透镜光路

#### 手法5：概念性"合理但错误"陷阱
- 选项本身在某些语境下是正确的物理陈述，但不适用于题目情境
- 例：Q5 电磁辐射传播速度，(C)(D)认为不同波长到达时间不同（对介质正确，对真空错误）
- 例：Q30 透镜成像，每个选项都引用了一个真实的光学原理，但只有一个正确适用

#### 手法6：数量级/系数陷阱
- 计算结果正确但漏乘/多乘一个系数（如2、4、pi等）
- 例：Q4 忘记乘以2e中的2、Q22 面积比例为直径比而非直径平方比

## 三、FRQ 深度分析

### 3.1 FRQ 类型与分值架构

Practice Exam 1 的 4 道 FRQ 有明确的类型标签：

| 题号 | 官方类型 | 总分 | 建议时间 | 占Section II |
|------|---------|------|---------|------------|
| **Q1** | Mathematical Routines（数学推导） | 10分 | 25分钟 | 12.5% |
| **Q2** | Translating Between Representations（表征转换） | 12分 | 30分钟 | 15% |
| **Q3** | Lab（实验设计） | 10分 | 25分钟 | 12.5% |
| **Q4** | Qualitative/Quantitative Translation（定性-定量转换） | 8分 | 20分钟 | 10% |

### 3.2 各类型 FRQ 的结构模板

#### 类型1：Mathematical Routines（Q1 光电效应）
```
结构模板：
(a)(i) Derive 表达式 → 要求从基本原理出发，写出方程并代入
(a)(ii) Calculate 数值 → 代入具体数字，带单位
(a)(iii) Sketch 图线 → 在给定坐标系上画线（斜率/截距有物理含义）
(b) Indicate + Justify → 定性判断 + 物理论证

关键词频：Derive(推导) > Calculate(计算) > Sketch(画图) > Justify(论证)
```

#### 类型2：Translating Between Representations（Q2 RC电路）
```
结构模板：
(a)(i)(ii) Draw 电路图 → 给定行为描述，画出对应电路
(b)(i) Derive 表达式 → 从 Kirchhoff 定律出发推导电流
(b)(ii) Determine 极限行为 → 长时间后电路的状态
(c) Sketch 两张图 → 电流-时间图 + 电压-时间图（含截距/渐近线标注）
(d) Indicate + Justify 比较 → 修改电路后的变化

关键词频：Draw(画图) > Derive(推导) > Sketch(画图) > Determine(确定) > Justify(论证)
```

#### 类型3：Lab（Q3 理想气体实验）
```
结构模板：
(a) Describe 实验步骤 → 足够详细让他人可重复，含减小不确定度措施
(b) Describe 数据分析方法 → 如何图形化验证关系（画什么 vs 什么）
(c)(i) Indicate 图形坐标 → 指定纵轴/横轴使斜率有物理含义
(c)(ii) Plot 数据点 → 在坐标纸上标轴、画点
(c)(iii) Draw 最佳拟合线
(d) Calculate 从图中 → 用斜率求物理量

关键词频：Describe(描述) > Indicate(指明) > Plot(作图) > Draw(画线) > Calculate(计算)
```

#### 类型4：Qualitative/Quantitative Translation（Q4 衍射光栅）
```
结构模板：
(a) Indicate + Justify（无方程）→ 定性判断并用物理概念（非数学）论证
(b) Derive 表达式 → 用数学推导得出比值关系
(c) Indicate consistency + Justify → 判断(b)的推导是否与(a)的定性分析一致

关键词频：Indicate(指明) > Justify(论证) > Derive(推导)
```

### 3.3 FRQ 评分模式的核心规则

从 Scoring Guidelines 中提取的关键评分原则：

#### 原则1：逐点赋分（Point-by-Point）
- 每个得分点独立，前一步错不影响后续步骤得分
- 明确的 "Scoring Note: This point can be earned for a correct substitution into an incorrect equation that is consistent with the response for (a)(i)"

#### 原则2：一致性原则（Consistency）
- 如果(a)推导错误，(b)基于错误的(a)做了正确的代入，仍可得分
- 这是CB评分最重要的哲学：考查推理过程，不因一个错误否定整个链条

#### 原则3：每个得分点有精确的必要条件
典型评分标准格式：
```
(a)(i) 1 point: 写出 K_max = hf - phi
       1 point: 正确将 v_max 代入动能表达式
       1 point: 用 c/lambda 替换 f
(a)(ii) 1 point: 正确代入数值
        1 point: 正确计算并给出单位
```

#### 原则4：图形评分有专门细则
- **曲线形状**（凹凸方向、单调性）
- **关键点标注**（截距值、渐近线值，必须用符号标注如 epsilon/R）
- **线段类型**（直线 vs 曲线，实线 vs 虚线）

#### 原则5：Justify 和 Explain 的评分差异
- **Justify**：需要引用物理原理 + 应用到具体情境 = 2个得分点
- **Indicate**：只需正确选择/陈述 = 1个得分点
- **Derive**：需要完整的数学推导链条，每步给分

### 3.4 各 FRQ 题的分值结构统计

| 题型 | 总分 | 推导/计算 | 画图/画电路 | 定性论证 |
|------|------|---------|---------|--------|
| Mathematical Routines | 10 | 5分(50%) | 2分(20%) | 3分(30%) |
| Translating Between Repr. | 12 | 4分(33%) | 6分(50%) | 2分(17%) |
| Lab | 10 | 2分(20%) | 3分(30%) | 5分(50%) |
| Qual/Quant Translation | 8 | 3分(38%) | 0分(0%) | 5分(62%) |

**关键发现**：定性论证（Justify/Explain）在总分中占比极高（约35-40%），这不是一个纯计算的考试。

## 四、Question Bank 与 Progress Check 补充分析

### 4.1 Question Bank 特征（U9 热力学为例）

- 每个 Unit 有独立题库，87页规模
- 题目按 Topic 编号（如 U9~1 = Unit 9 Topic 1）
- 大量使用 **Maxwell-Boltzmann 速度分布图**考查气体动力学
- **活塞-注射器-容器**类实验装置图出现频率极高
- 表格型选项（两列对比）是 Unit 9 的标志性题型

### 4.2 Progress Check FRQ 特征

以 Unit 12（磁场/电磁感应）FRQ1 为例：
- **情境**：导线环进入磁场区域
- **Part A (7分)**：Derive 外力表达式 + Sketch 磁通量图
- **Part B (3分)**：Rank 三个位置的感应电流大小 + Justify
- 评分极其精细，图形的每个区间行为分别给分

以 Unit 14（波动）FRQ1 为例：
- **情境**：弦上驻波
- **Part A**：Derive 张力表达式 + Sketch 改变频率后的驻波 + Indicate/Justify 改变条件后的变化
- 多场景对比（Scenario X/Y/Z）是常见设计模式

## 五、CB出题者的核心设计哲学

### 5.1 三大考查维度

1. **概念理解（~40%）**：能否用物理语言解释现象，区分相近概念
2. **数学推理（~30%）**：能否从基本方程出发推导表达式，进行符号和数值计算
3. **表征转换（~30%）**：能否在文字、图形、方程、数据之间自如转换

### 5.2 七大高频动词（由高到低）

| 动词 | 含义 | 出题频率 |
|------|------|---------|
| **Justify** | 用物理原理论证你的答案 | 最高 |
| **Derive** | 从基本原理推导表达式 | 高 |
| **Indicate** | 选择/陈述结论 | 高 |
| **Sketch** | 在坐标系上画定性图 | 高 |
| **Calculate** | 代入数值求结果 | 中 |
| **Describe** | 描述实验步骤/现象 | 中（Lab题） |
| **Draw** | 画电路图/力图 | 中 |

### 5.3 出题者最爱设置陷阱的物理2考点

| 排名 | 陷阱考点 | 典型错误 |
|------|---------|---------|
| 1 | **RC电路暂态行为** | 混淆充电/放电的初始/最终状态 |
| 2 | **电荷感应起电** | 忘记最终两球分离后电荷分布不对称 |
| 3 | **磁力方向（右手定则+负电荷）** | 负电荷使用右手定则后忘记反向 |
| 4 | **光电效应中光强vs频率** | 混淆增大光强和改变颜色的效果 |
| 5 | **PV图中功的计算** | 搞错功的正负号（系统做功 vs 对系统做功） |
| 6 | **衍射vs干涉图样变化** | 缝宽减小时中央极大变宽而非变窄 |
| 7 | **电容器断开后改变间距** | 混淆Q恒定时C/V的变化关系 |
| 8 | **核衰变中粒子识别** | 混淆alpha/beta/gamma和中子的质量数/电荷数 |

### 5.4 出题的"脚手架"递进策略

CB在FRQ中系统使用递进式提问：

```
Level 1 (Indicate): 给出答案 → 1分
Level 2 (Justify):  解释原因 → +1分
Level 3 (Derive):   数学推导 → +2~3分
Level 4 (Predict):  预测新情境 → +1~2分
Level 5 (Evaluate): 评价一致性 → +1分
```

每道FRQ都是从"容易得分"到"困难得分"的梯度设计，确保不同水平的学生都能拿到部分分。

## 六、出题模式速查表（用于AI出题参考）

### MCQ 出题清单
- [ ] 4选项，始终ABCD
- [ ] 70%+ 题目带图/表/图形
- [ ] 至少1个干扰项是"方向反转"
- [ ] 至少1个干扰项是"公式变量混淆"
- [ ] 表格型选项用于同时考查两个物理量变化
- [ ] 每题对应明确的 Learning Objective 和 Essential Knowledge 编码
- [ ] 每题对应明确的 Skill 编码（2.A/2.B/3.B 为主）

### FRQ 出题清单
- [ ] 4种题型轮换：Mathematical Routines / Translating Between Repr. / Lab / Qual-Quant Translation
- [ ] 分值分配：10/12/10/8
- [ ] 每个 part 有明确的动词（Derive/Calculate/Sketch/Indicate/Justify/Describe/Draw）
- [ ] 评分必须逐点独立，支持一致性得分
- [ ] 图形评分需指定：形状、关键点标注、坐标范围
- [ ] Lab题必须包含：实验步骤描述 + 数据分析方法 + 作图 + 从斜率求值
- [ ] 最后一个 part 通常是 "Indicate consistency + Justify"
