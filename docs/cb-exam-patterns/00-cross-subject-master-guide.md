# College Board AP 出题者模式总纲

> 基于 7 个 AP 学科（环境科学、统计、微观经济、化学、物理1、微积分AB、微积分BC）的 CB 官方题库深度分析

---

## 一、CB 出题的通用架构

### MCQ 六大题干模式（跨学科通用）

| 模式 | 描述 | 跨学科出现率 |
|------|------|------------|
| **图表/图片引入型** | 提供图表 → 读图 → 推断 | 所有学科最高频（30-45%） |
| **情景叙事引入型** | 2-5 句真实情景 → 应用判断 | 统计/环科/经济（25-45%） |
| **直接概念提问型** | 无 stimulus，直接考定义/性质 | 所有学科（10-20%） |
| **数据表计算型** | 给数值表 → 计算/比较 | 统计/经济/微积分（10-20%） |
| **共享 stimulus 题组** | 同一张图/情景 → 2-4 连续题 | 环科/化学/经济 |
| **否定限定型** | EXCEPT / NOT / LEAST | 所有学科（5-8%） |

### FRQ 通用递进结构

所有学科的 FRQ 都遵循相同的认知递进模式：

```
Part (a): 基础操作（识别/计算/画图）      → 记忆+应用
Part (b): 应用判断（分析数据/选择方法）    → 应用
Part (c): 定量/定性分析（计算+解释）       → 应用+分析
Part (d): 推理延伸（预测变化/评估影响）    → 分析
Part (e+): 高阶综合（跨主题/政策评估）     → 分析+评价
```

## 二、CB 干扰项设计的 8 大通用手法

| # | 手法 | 说明 | 出现学科 |
|---|------|------|---------|
| 1 | **概念相近混淆** | 用相似但不同的术语/概念 | 全部 |
| 2 | **因果倒置** | 结果写成原因，或因果方向反转 | 全部 |
| 3 | **部分正确** | 前半句对后半句错，或只考虑了一个变量 | 环科/化学/经济 |
| 4 | **总量 vs 边际量** | 用 total 干扰 marginal（或平均干扰边际） | 经济/统计 |
| 5 | **符号/方向错误** | 正负号反、大于小于反、偏态方向反 | 微积分/统计/物理 |
| 6 | **尺度/层级混淆** | 分子 vs 分子间、样本 vs 总体、短期 vs 长期 | 化学/统计/经济 |
| 7 | **公式漏项** | 漏乘链式法则、漏除 sqrt(n)、漏考虑距离 | 微积分/统计/化学 |
| 8 | **过度泛化** | 把特例说成普遍规律，或把必要条件说成充分条件 | 统计/环科 |

## 三、学科特异性对比

### MCQ Stimulus 偏好

| 学科 | 主要 Stimulus 类型 | 图表依赖度 |
|------|-------------------|-----------|
| **环境科学** | 食物网、生物群落气候图、年龄金字塔、存活曲线 | 40-50% |
| **统计** | 直方图、箱线图、散点图、双向频率表、模拟分布 | 25-35% |
| **微观经济** | MC/ATC/D/MR 曲线图、生产函数表、博弈矩阵 | 40-50% |
| **化学** | 数据比较表、Lewis 结构、粒子模型图、校准曲线 | 30% |
| **物理1** | v-t 图、x-t 图、F-x 图、运动示意图 | 60%+ |
| **微积分** | 函数图（开闭圆点）、f'/f'' 图、数据逼近表 | 30-40% |

### FRQ 核心差异

| 学科 | FRQ 核心动作 | 特有要求 |
|------|------------|---------|
| **环境科学** | Identify → Describe → Explain → Make a claim | "Make a claim using evidence" 是标志性动词 |
| **统计** | State hypotheses → Check conditions → Calculate → Conclude in context | 必须用情景语言，"in context" 是独立得分点 |
| **微观经济** | Calculate → Draw graph → Explain using marginal analysis → Predict long-run | 画图必须标注所有轴/曲线，"Show your work" |
| **化学** | Write equation → Calculate → Justify in terms of Coulomb's law | Coulomb's law 论证是万能模板 |
| **物理1** | Draw FBD → Derive expression → Indicate + Justify | 符号推导（不代入数值），FBD 是入场券 |
| **微积分** | Find/Evaluate → Justify your answer → Explain the meaning with units | 必须引用定理名称 + 验证前提条件 |

## 四、各学科 MCQ 认知层次分布

| 层次 | 环科 | 统计 | 经济 | 化学 | 物理 | 微积分 |
|------|------|------|------|------|------|--------|
| 记忆 | 15% | 10% | 10% | 15% | 5% | 10% |
| 理解 | 30% | 35% | 25% | 45% | 35% | 25% |
| 应用 | 35% | 35% | 40% | 30% | 40% | 40% |
| 分析 | 20% | 20% | 25% | 10% | 20% | 25% |

**关键发现**：CB 所有学科都重应用+分析（合计 55-65%），纯记忆题 ≤ 15%。

## 五、CB 出题的 10 条铁律

### 1. 视觉材料为王
所有学科 MCQ 中 30-60% 包含图表/图片。FRQ 中比例更高（环科新版 100%）。

### 2. 模板高度复用
CB 有一个有限的核心模板库，通过改变数值/情景/图形生成大量变体。掌握模板 = 掌握考试。

### 3. 情景真实性
几乎不存在纯抽象题。即使考公式，也包裹在真实情景中（统计尤其如此）。

### 4. 动词即评分指令
Identify（点名即可）< Describe（描述特征）< Explain（因果推理）< Justify（引用原理论证）< Make a claim（立场+证据）。动词精度直接决定得分。

### 5. 各 Part 独立评分
FRQ 的每个 Part 独立计分。前面答错不影响后面得分（carry-through 原则）。

### 6. "正确解释"是最大区分度来源
置信区间的含义、p 值的含义、导数的物理意义、面积的经济学含义——CB 反复从不同角度考"你真的理解这个概念吗"。

### 7. 干扰项基于真实误区
每个干扰项都对应学生的常见错误，不是随机生成的。出题时应参考教学中的高频错误。

### 8. 否定词必大写
EXCEPT / NOT / LEAST 一律大写加粗，频率约 5-8%。

### 9. 选项从 5 个向 4 个过渡
新版考试统一 4 选项 (A-D)，旧题库仍有 5 选项。出题应以 4 选项为标准。

### 10. 跨单元综合是 FRQ 常态
一道 FRQ 通常跨 2-3 个 Unit。纯考单一知识点的 FRQ 几乎不存在。

## 七、出题系统集成建议

### 生成 MCQ 时的必备参数

```typescript
interface CBStyleMCQ {
  subject: string;            // AP 学科
  unit: number;               // 单元号
  cognitiveLevel: 'recall' | 'understand' | 'apply' | 'analyze';
  stimulusType: 'graph' | 'table' | 'scenario' | 'direct' | 'shared-set';
  distractorStrategy: string; // 使用的干扰项手法（见 8 大手法）
  negativeForm: boolean;      // 是否 EXCEPT/NOT
  calculatorRequired: boolean;
}
```

### 生成 FRQ 时的必备参数

```typescript
interface CBStyleFRQ {
  subject: string;
  units: number[];           // 跨哪几个单元
  partCount: number;         // Part 数量
  parts: Array<{
    verb: 'identify' | 'describe' | 'explain' | 'calculate' | 'justify' | 'draw' | 'make-a-claim' | 'derive';
    points: number;
    requiresShowWork: boolean;
    requiresContext: boolean; // 统计学特有
    requiresGraph: boolean;  // 经济/物理特有
  }>;
  template: string;          // 使用的模板编号（如 STAT-F1）
}
```
