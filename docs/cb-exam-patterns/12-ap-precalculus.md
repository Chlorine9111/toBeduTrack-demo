## 第二部分：MCQ 出题模式深度分析

### 2.1 题干结构分类（基于 Practice Exam 28 题 + Progress Check）

通过对 40+ 道 MCQ 的逐题分类，CB 使用以下六种题干模板：

| 题干类型 | 占比 | 典型问法 | 实例 |
|---------|------|---------|------|
| **代数操作型** | ~25% | "Which is an equivalent form?" | Q2: f(x)=9*25^x 的等价形式；Q5: 2ln x - 3ln y 的等价形式；Q13: 7sin(2x) 的等价形式 |
| **图表解读型** | ~25% | 给图/表 → 判断性质 | Q3: 图中判断递增+下凹区间；Q8: 正弦图求周期；Q9: 分段函数变换后选图；Q14: "输入翻倍、输出+1" 选图 |
| **概念判断型** | ~20% | "Which statement is true?" | Q4: 端行为判断；Q10: 指数增长/衰减判断；Q21: hole vs. 竖直渐近线判断；Q23: 复数零点与共轭关系 |
| **计算求值型** | ~15% | 直接计算得数值 | Q11: f(g(x)) 的表达式；Q18: h(0) = f(g(0)) 查表求值；Q24: 对数方程交点 |
| **建模应用型** | ~10% | 真实情境 → 建模 | Q22: 社交媒体粉丝数据建模；Q27: 自行车踏板高度建模 |
| **变换推理型** | ~5% | 函数变换序列 | Q17: 垂直伸缩因子 2；Q19: g(x)=f(2(x-4)) 的水平变换序列 |

### 2.2 四选项干扰项设计手法（CB 核心套路）

通过逐题分析选项设计，CB 使用以下 7 种干扰项策略：

#### 策略 1：符号/方向错误（最常见）
- **Q1**：p(x) = -x(x-4)(x+2) >= 0，正确答案 D 是 (-inf, -2] U [0, 4]。干扰项 C 是 (-inf, -4] U [0, 2]，将零点 -2 和 4 的位置互换（把因子的零点搞混）
- **Q4**：f(x) = 5x^6 - 2x^3 - 3 的端行为，偶数次最高项 → 两端同向。干扰项 A 和 C 给出两端异向，测试学生是否混淆奇偶次多项式

#### 策略 2：运算法则混淆
- **Q5**：2ln x - 3ln y，正确答案 A 是 ln(x^2/y^3)。干扰项 C 是 ln(2x-3y)（加减法与乘除法混淆），干扰项 D 是 ln(2x/3y)（系数变为乘数而非指数）
- **Q2**：f(x) = 9*25^x，正确答案 D 是 9*5^(2x)。干扰项 A 是 3*5^(x/2)，将 9=3^2 与 25=5^2 的拆分搞混

#### 策略 3：分母中公共因子的 hole vs. asymptote 陷阱
- **Q7**：有理函数有竖直渐近线 x=-5。选项 B 的分子分母都含 (x+5)，会约掉形成 hole 而非渐近线。CB 精确测试学生是否区分"可约因子"（hole）与"不可约因子"（渐近线）
- **Q21**：分子在 x=1 有零点，分母在 x=1 和 x=7 都有零点，且 x=1 处重数相等 → x=1 是 hole，x=7 是竖直渐近线

#### 策略 4：图形变换方向反转
- **Q9**：y = f(x+1) - 2 要求左移1+下移2。四个选项图系统性地测试：右移（+1 vs -1 方向错误）和上移（-2 vs +2 方向错误）的排列组合
- **Q19**：g(x) = f(2(x-4))，正确是水平压缩 1/2 再右移 4。干扰项系统测试"压缩 vs 拉伸"和"移动方向正负号"的组合错误

#### 策略 5：指数/对数参数混淆
- **Q10**：表格数据 f(0)=3/4, f(1)=3/2, f(2)=3, f(3)=6, f(4)=12，每次乘以 2 → 增长。干扰项 A 和 C 将 a>0 与 0<b<1 的组合与增长/衰减搞混
- **Q22**：社交媒体数据 P(0)=20, P(1)=30, P(2)=45...比值为 1.5 → 指数模型 y=20(3/2)^t。干扰项包含线性模型和错误底数

#### 策略 6：三角恒等式的"几乎正确"形式
- **Q13**：7sin(2x) = 14cos(x)sin(x) 是正确答案 A。干扰项 B 是 (7cos x)(7sin x) = 49cos(x)sin(x)（系数分配错误），干扰项 C/D 用了 cos^2 和 sin^2 的二倍角公式变形
- **Q20**：从正弦图形反推 f(x) 表达式，四个选项在 cos/sin 和相移 pi/4 vs pi/8 之间设置干扰

#### 策略 7：极坐标中"距离=|r|"的概念陷阱
- **Q26**：r = 4cos(2theta) 的四叶玫瑰线，限制域后哪段图仍保留。测试学生是否理解负 r 值意味着图在对称位置
- **Q28**：r = 1+2sin(theta) 的距离分析，干扰项混淆"r 为正且递增"与"距离递增"的区别（当 r 为负时距离 = |r|）

### 2.3 Calculator vs. No-Calculator 区分规律

| 特征 | Part A（无计算器，28题） | Part B（有计算器，12题） |
|------|------------------------|------------------------|
| **数值特点** | 使用整数、简单分数、特殊角度值 | 使用小数、非标准角度、需数值逼近 |
| **函数系数** | 系数为 1, 2, 3, 5 等小整数 | 系数可为小数如 2.5, 0.992408 |
| **图形** | 提供精确图形，可直接读取关键点 | 可能需要用计算器绘图后判断 |
| **解法** | 因式分解、代数恒等式、特殊值 | 数值求解、回归分析、数值逼近 |
| **典型区分** | Q25: 解 2sin^2(theta) = -sin(theta)，解为特殊角 | FRQ Part B Q4/Q5: f(0.739)=-8.832 需计算器求极值 |

### 2.4 Skill 分布（从答案对照表提取）

CB 定义了四种技能，MCQ 覆盖分布：

| Skill | 描述 | Part A 占比 | Part B 占比 |
|-------|------|-----------|-----------|
| 1.A | 确定函数变化 | 3 题 | 1 题 |
| 1.B | 确定等价表示 | 5 题 | 0 题 |
| 1.C | 解释数学信息 | 3 题 | 1 题 |
| 2.A | 用数学方法证明 | 3 题 | 2 题 |
| 2.B | 证明函数模型的合理性 | 2 题 | 2 题 |
| 3.A | 确定关键特征 | 5 题 | 1 题 |
| 3.B | 描述函数行为 | 0 题 | 4 题 |
| 3.C | 推理得出结论 | 7 题 | 0 题 |

**关键发现**：Part A（无计算器）偏重 3.C（推理结论）和 3.A（关键特征），Part B（有计算器）偏重 3.B（描述行为）和 2.B（建模论证）。

## 第三部分：FRQ 出题模式深度分析

### 3.1 FRQ 整体架构

AP Precalculus 的 FRQ 与 AP Calculus 有根本区别：

| 维度 | AP Precalculus FRQ | AP Calculus FRQ |
|------|-------------------|-----------------|
| **核心动词** | Find, Determine, Interpret, Rewrite | Find, Show, Justify, Prove |
| **是否需要微积分** | 完全不需要 | 需要求导/积分 |
| **情境依赖** | 强依赖真实情境（噪音衰减、细菌培养、行星轨道） | 情境较抽象 |
| **计算器依赖** | Part A 需要计算器求解（非标准数值），Part B 纯代数 | 类似分区 |
| **"Rate of change"** | 仅计算平均变化率（斜率），不涉及瞬时变化率 | 瞬时变化率（导数） |
| **推理深度** | 解释+应用为主 | 证明+推导为主 |

### 3.2 FRQ 的三种固定模板

通过分析 Unit 1/2/3 的 FRQ Part A 和 Part B，CB 使用以下三种高度固定的模板：

#### 模板一：「建模三步曲」（Unit 2/3 最爱用）

**结构**：Part A → Part B → Part C，层层递进：

| 步骤 | 内容 | 分值 | 实例 |
|------|------|------|------|
| Part A | 用数据建立模型（列方程、求参数 a,b） | 2 分 | Unit 2: S(d)=ab^d, 由 S(0)=105, S(100)=49 求 a=105, b=0.992 |
| Part B | (i) 算平均变化率 (ii) 解释含义 (iii) 用平均变化率估计 | 3 分 | (49-105)/100 = -0.56 dB/m → "每增加1米，噪音平均降低0.56分贝" |
| Part C | 反向求解（已知输出求输入）或判断增长/衰减 | 1 分 | S(m)=20 → m=217.575 米 |

**这个模板在三个单元的 FRQ Part A 中完全一致**：
- Unit 2 风力发电噪音衰减：S(d) = 105(0.992)^d
- Unit 2 细菌培养面积增长：C(t) = 0.4(1.5)^t
- Unit 3 金星轨道距离：D(t) = 0.7cos(2pi/225 * t) + 108.2
- Unit 3 风车叶片高度：h(t) = 40sin(pi/3(t+1.5)) + 75

#### 模板二：「多项式/有理函数分析」（Unit 1 专属）

**Part A（需计算器）结构**：

| 步骤 | 内容 | 分值 |
|------|------|------|
| Part A | 闭区间上求绝对极值（需计算器求小数点坐标） | 2 分 |
| Part B | 求所有实数零点 | 2 分 |
| Part C | 非实数零点的最大可能数量（需推理：次数-实零点数） | 2 分 |

**Part B（无计算器）结构**：

| 步骤 | 内容 | 分值 |
|------|------|------|
| Part A | 有理函数的竖直渐近线（区分 hole vs. asymptote） | 2 分 |
| Part B | 有理函数的实零点（排除 hole 处） | 2 分 |
| Part C | 水平/斜渐近线（比较分子分母次数） | 1-2 分 |

#### 模板三：「三角恒等式+方程求解」（Unit 3 Part B 专属）

| 步骤 | 内容 | 分值 |
|------|------|------|
| Part A | 三角恒等式化简（如 sec x/csc x = tan x，sin(2x)/cos x = 2sin x） | 2 分 |
| Part B | 在指定区间/定义域上解三角方程 | 2 分 |
| Part C | 含参三角方程的通解（需写 + 2npi 的一般形式） | 2 分 |

### 3.3 FRQ 评分模式（关键发现）

CB 的评分采用「分析型评分」(Analytic Scoring)，每个 Part 独立 0/1/2 或 0/1/2/3 分：

**评分标准的一致模式**：

| 分值 | 含义 |
|------|------|
| 0 分 | 没有有效尝试 |
| 1 分 | 完成一半（如只找到一个零点、只列出方程但未求解） |
| 满分 | 两个条件都满足（标注为 bullet points） |

**评分中的关键细节**：
1. **必须有标签**：求极值时必须标注"absolute minimum"/"absolute maximum"，缺标签扣分
2. **不能多写**：找到两个零点满分，但如果多写一个错误零点降为 1 分（"No other zeros"是评分标准之一）
3. **接受近似**：计算器题允许合理四舍五入，如 b=0.992408 用 0.992 也可接受
4. **解释必须含情境**：Part B(ii) 的"Interpret"必须包含具体单位和变量含义（"噪音每米降低0.56分贝"），纯数学表述不得分

### 3.4 FRQ 的"必背句式"

从 Model Solutions 中提取的标准表达：

**平均变化率**：
> "On average, as [自变量] increases from [a] to [b] [单位], the [因变量] [increases/decreases] [数值] [单位] per [自变量单位]."

**指数增长/衰减判断**：
> "Because a > 0 and b > 1 in the model C = ab^t, the model demonstrates exponential growth."

**竖直渐近线推理**：
> "Because [值] is a real zero of the polynomial in the denominator of [函数] and not a real zero of the polynomial in the numerator, the graph has a vertical asymptote at x = [值]."

**Hole 的推理**：
> "Because the multiplicity of the real zero [值] in the numerator is equal to its multiplicity in the denominator, the graph has a hole at x = [值]."

**非实数零点**：
> "The degree of the polynomial is [n]. Because [函数] has [k] real zeros, [函数] can have at most [n-k] non-real zeros."

## 第四部分：按考点的出题模式清单

### 4.1 Unit 1：多项式与有理函数

| 考点 | MCQ 典型出法 | FRQ 典型出法 | CB 最爱的陷阱 |
|------|-----------|-----------|------------|
| **零点与因式分解** | 给因式形式 → 判断零点数量或位置 | 用计算器求实数零点 + 推理非实零点 | 共轭复数根必须成对；分母零点不是函数零点 |
| **端行为** | 给多项式 → 判断两端极限方向 | 少见 | 偶数次 vs 奇数次最高项；负系数反转方向 |
| **凹凸性** | 给图 → 判断凹上/凹下区间；给表 → 算二阶差分 | 少见 | "average rate of change 递减 → concave down"（不是递增！） |
| **有理函数** | 给因式 → 判断 hole vs. asymptote | 完整分析：竖直渐近线 + 零点 + 水平/斜渐近线 | (x-1) 同时出现在分子分母 → hole 不是渐近线 |
| **函数变换** | 给变换公式 → 选正确图形或描述序列 | 少见 | f(x+1)-2: +1 是左移不是右移；水平伸缩 1/b 不是 b |
| **奇偶函数** | 给函数 → 选支持奇/偶性的等式 | 少见 | f(-3) = -f(3) 支持奇函数；f(0) = -f(0) 不充分（因为都=0） |

### 4.2 Unit 2：指数与对数函数

| 考点 | MCQ 典型出法 | FRQ 典型出法 | CB 最爱的陷阱 |
|------|-----------|-----------|------------|
| **指数形式转换** | 9*25^x = ? 的等价形式 | 少见 | 9=3^2, 25=5^2 → 9*25^x = 9*5^(2x)；不能把9拆进指数 |
| **对数运算律** | 2ln x - 3ln y = ? | 少见 | 系数变指数而非乘数：2ln x = ln(x^2) 不是 ln(2x) |
| **指数增长/衰减判断** | 给数据表 → 判断是增长还是衰减 | Part C 必考："a>0, b>1 → growth" | 比值恒定 → 指数；差值恒定 → 线性 |
| **建模** | 给数据 → 选最佳模型（线性 vs 指数） | 三步曲：建模 → 平均变化率 → 估计 | 线性模型用差值；指数模型用比值。二阶差分恒定 → 二次模型 |
| **对数方程求解** | log(x-1) + log(x+3) = log(x+9) 交点 | 少见 | 合并后解二次方程可能产生伪解（使对数定义域无效） |
| **函数组合** | f(g(x)) 的表达式或 f(g(0)) 查表求值 | 少见 | 复合函数先算内层再代入外层；查表题注意定义域 |

### 4.3 Unit 3：三角与极坐标函数

| 考点 | MCQ 典型出法 | FRQ 典型出法 | CB 最爱的陷阱 |
|------|-----------|-----------|------------|
| **正弦建模** | 给实际情境图 → 求周期/振幅/表达式 | 三步曲（行星轨道、风车叶片） | 振幅=(max-min)/2；中线=(max+min)/2；周期=2pi/b |
| **三角恒等式** | 7sin(2x) 的等价形式 | sec/csc 化简、sin(2x)/cos(x) 化简 | sin(2x)=2sin(x)cos(x)；系数不能分配到各因子 |
| **三角方程** | 解 2sin^2(theta) = -sin(theta)（特殊角） | 通解 + 2npi/n 形式 | 因式分解后每个因子都要解；不要丢 sin(theta)=0 的解 |
| **单位圆与 sin/cos 定义** | 给圆上点坐标 → 判断 sin(theta) | 少见 | sin(theta) = y/r（纵坐标/半径），不是 x/r |
| **极坐标图形** | r = 4cos(2theta) 限制域后的图形部分 | 求极坐标中距原点最远的点 | 距离 = |r| 不是 r；r<0 时点在反方向 |
| **反三角函数** | 少见于 MCQ | 求 sin^(-1)(2x) = pi/4 的解 | 定义域限制：sin^(-1) 的输入在 [-1,1]，输出在 [-pi/2, pi/2] |
| **极坐标函数零点** | 少见 | 求 f(theta)=0 + 解释"图经过原点" | 零点的几何意义：图在该角度穿过极点（原点） |

## 第五部分：高频陷阱总结（考前必看清单）

### 5.1 计算类陷阱 TOP 5

1. **对数的加减法不等于内部的乘除法**：ln(a) - ln(b) = ln(a/b)，不是 ln(a-b)
2. **指数形式转换时系数的处理**：9*25^x 中 9 不是指数的一部分，不能写成 (9*25)^x
3. **复合函数的求值顺序**：f(g(x)) 先算 g(x)，再把结果代入 f
4. **三角方程因式分解后不要丢根**：2sin^2(theta) + sin(theta) = 0 → sin(theta)(2sin(theta)+1) = 0，sin(theta)=0 也是解
5. **有理函数零点排除 hole**：分子零点若与分母共享（且重数相同），该点是 hole 不是零点

### 5.2 概念类陷阱 TOP 5

1. **Hole vs. 竖直渐近线**：分子分母公共因子（重数相等）→ hole；分母独有因子 → 竖直渐近线
2. **水平变换方向**：f(x+1) 是左移 1，不是右移；f(2x) 是水平压缩 1/2，不是拉伸 2
3. **端行为判断**：看最高次项的系数和次数。偶数次两端同向，奇数次两端异向
4. **极坐标距离**：距原点的距离 = |r|（绝对值），r 为负时点在角度的反方向
5. **凹凸性判断**：average rate of change 递增 → concave up；递减 → concave down

### 5.3 FRQ 写作类陷阱 TOP 3

1. **Interpret 必须包含情境**：不能只写 "-0.56"，必须写 "the noise level decreases by 0.56 decibels per meter on average"
2. **极值必须标注**：写 "absolute minimum is -8.832"，不能只写数字
3. **通解要写 + 2npi*n**：三角方程的通解必须包含 "where n is any integer"

| 5 | 3.10.A（三角方程求解） | 2 次 | 特殊角、区间解 |
| 6 | 2.14.A（半对数图/指数模型） | 2 次 | 指数函数图形识别 |

### 6.2 备考优先级矩阵

| 优先级 | 考点 | 理由 |
|--------|------|------|
| **最高** | 正弦建模（参数 a, b, c, d 的确定） | MCQ+FRQ 都是最高频考点 |
| **最高** | 指数模型建立（ab^t 求 a 和 b） | FRQ Part A 模板化考点，必拿分 |
| **最高** | 平均变化率（计算+解释+估计） | 每个 FRQ Part A 的 Part B 都考 |
| **高** | 有理函数（hole/asymptote/零点） | Unit 1 FRQ Part B 固定考点 |
| **高** | 函数变换（平移+伸缩的方向和顺序） | MCQ 高频；变换方向是最常见错误 |
| **高** | 三角恒等式化简 | FRQ Part B 固定考点 |
| **中** | 极坐标函数（零点含义、距离=|r|） | Unit 3 特有，MCQ+FRQ 都考 |
| **中** | 多项式端行为与凹凸性 | MCQ 概念题常考 |
| **中** | 对数运算律 | MCQ 代数操作题常考 |
| **较低** | 复数零点/共轭复数 | 偶尔出现，概念理解即可 |

## 第七部分：出题者思维模式总结

### 7.1 CB 出题的三大核心原则

1. **"概念先于计算"**：CB 极少考纯粹的计算技巧，几乎每道题都在测试概念理解。即使是"求等价形式"，也在测试学生是否真正理解对数运算律，而非机械套公式。

2. **"干扰项来自真实错误"**：CB 的每个干扰项都对应学生的一种典型错误思维。分析干扰项就能知道 CB 预期学生会犯什么错。

3. **"FRQ 模板高度固化"**：尤其是 Unit 2/3 的 FRQ Part A，几乎完全相同的三步曲结构（建模 → 平均变化率 → 反向求解），只是换了情境。掌握一个模板 = 掌握所有同类 FRQ。

### 7.2 AP Precalculus 与 AP Calculus 的衔接信号

CB 在 Precalculus 中故意埋入了大量"pre-Calculus"概念：
- **平均变化率** → Calculus 中的割线斜率 → 导数的前身
- **凹凸性通过二阶差分判断** → Calculus 中的二阶导数
- **端行为用极限符号表示** → Calculus 中的极限概念
- **"rate of change is increasing"** → Calculus 中的"二阶导数为正"

这说明 CB 的设计意图是让 AP Precalculus 成为 AP Calculus 的直接"预科课程"，题目中的思维方式已经在为微积分做准备。
