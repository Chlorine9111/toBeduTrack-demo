# AP 生物 CB 出题者模式手册

---

## 第一部分：MCQ（选择题）深度分析

### 一、题干结构分类与比例

CB 的 AP 生物 MCQ 呈现**五种核心题干结构**，按出现频率排序：

#### 1. 实验情景型（约 35-40%）——最高频

**模板**：给出一个完整的实验描述（研究者做了什么、用了什么材料、测了什么变量），然后问结论/预测/解释。

**典型信号词**：
- "Researchers investigated..."
- "Scientists examined..."
- "A student designs an experiment..."
- "In an experiment, bacteriophages were labeled with..."

**实例模式**：
- Q3：突变酶实验 -- 丝氨酸被苯丙氨酸替换 -> 酶活性降低 -> 问为什么
- Q6：噬菌体标记实验（经典 Hershey-Chase 复现）-> 推断注入了什么分子
- Q12：不同环境中蛋白质的半胱氨酸含量比较 -> 推断对稳定性的影响

**出题者手法**：实验描述中故意埋入**1-2个关键细节**，正确答案必须同时捕捉到这些细节。遗漏任何一个都会选错。

#### 2. 图表数据型（约 25-30%）——第二高频

**Stimulus 类型清单**（按出现频率排序）：

| Stimulus 类型 | 出现频率 | 典型考点 |
|-------------|--------|--------|
| 柱状图（带误差棒） | 最高频 | 统计显著性判断、组间比较 |
| 数据表（含均值 +/- 2SE） | 高频 | 误差棒重叠判断、趋势描述 |
| 散点图/折线图 | 中频 | 相关性、因变量识别 |
| 凝胶电泳图 | 中频 | 基因型推断、片段大小比较 |
| 系谱图（Pedigree） | 中频 | 遗传方式判断、携带者推断 |
| 分子结构图 | 中频 | 官能团识别、分子比较 |
| 食物网/能量流图 | 低频 | 营养级关系、生态扰动预测 |
| 细胞/膜结构示意图 | 低频 | 跨膜运输、细胞器功能 |

**关键发现**：CB 极度偏爱**带误差棒的柱状图**和**含 +/- 2SE 的数据表**。这是因为 AP Bio 的 Science Practice 第 2 项明确要求"Analyze Data"，而误差棒重叠判断是核心考查点。

#### 3. 分子结构/图解型（约 15-20%）

**模板**：给出化学结构式/细胞结构图/DNA/蛋白质模型图，要求从结构推功能。

**典型 Stimulus**：
- 氨基酸结构式（半胱氨酸的 SH 基团 -> S-S 键 -> 稳定性）
- 脂肪酸结构（亚油酸 vs 棕榈酸 -> 双键 -> 室温固液态）
- 核酸片段（5' -> 3' 方向，核糖/脱氧核糖区分）
- 氢键示意图（水-氨 之间）
- 二肽/三肽结构（肽键方向、R 基团位置）

**出题者心思**：让学生**从图中读取未被文字直接描述的信息**。图中细节（如 OH vs H 在糖环上、双键造成的弯折）才是答题关键。

#### 4. 直接概念型（约 10-15%）

**模板**：不给实验/图表，直接问概念定义或原理。

**特征**：题干通常只有 1-2 句话。

**实例**：
- Q9："Which of the following is responsible for the cohesive property of water?"
- Q11："If 30% of nucleotides in RNA are adenine, what percent are thymine?" （0% -- RNA 无 thymine）

**注意**：这类题在 AP Bio 中占比较低（与 AP 化学/物理不同），因为 CB 更强调应用和分析能力。

#### 5. 研究者声明/论证型（约 10%）

**模板**："A researcher claims that..." -> "Which of the following best supports/evaluates this claim?"

**实例**：
- Q8（Energy）："A researcher claims that increased CO2 causes increased growth in plants."
- Q9（Energy）："A researcher claims that ATP synthesis from ADP and Pi is essential."
- Q29（Evolution）：科学家声明灭绝率 -> 选合适的零假设

**出题者意图**：考查 Science Practice 6（Argumentation），即评估证据是否支持声明。

### 二、选项设计与干扰项手法

CB 出题者使用了**6种系统化的干扰项制造策略**：

#### 策略 1：机制正确但方向/结论错误（最常见）

**实例**（Q1 CFTR蛋白）：
- 选项 B："affect primary structure, but other levels will NOT be affected" -- 机制描述半对半错
- 正确答案 D："affect primary, secondary, AND tertiary" -- 删除一个氨基酸必然影响所有层级

**模式**：使用正确的生物学术语，但在因果链条中偷换一个逻辑环节。

#### 策略 2：常见误解/朴素概念陷阱

**实例**（Q8 兔子碳来源）：
- 选项 A："use energy from plants to make carbon atoms from electrons, protons, and neutrons" -- 利用"制造原子"的朴素误解
- 选项 C："hydrolyze CO2" -- 水解一词的误用
- 正确答案 B："break down plant molecules to obtain carbon and rearrange into new molecules"

**模式**：故意设计选项迎合学生的**前概念（preconception）**，如"能量可以创造物质"。

#### 策略 3：范围过大或过小

**实例**（Q2 蛋白质折叠）：
- 选项 A："ionic bonds with charged ends of water" -- 范围过小（不是主要驱动力）
- 选项 D："covalent bonds between different R groups" -- 把非共价相互作用说成共价键
- 正确答案 C："Nonpolar R groups pushed into middle" -- 疏水效应是核心驱动力

#### 策略 4：四选项中用同一对关键词排列组合

**实例**（Q13 淀粉酶 vs 糖原合酶）：
- 四个选项都是"hydrolysis/dehydration" + "break/form covalent bonds" + "amylase/glycogen synthase"的排列组合
- 学生必须同时知道：(1) 哪个酶做什么 (2) 水解=加水断键 vs 脱水=去水成键

**模式**：用**2x2矩阵**生成四个选项，让学生必须在两个维度上同时判断正确。

#### 策略 5：似是而非的"听起来很学术"的选项

**实例**（Q3 突变酶）：
- 选项 C："caused many copies to cluster together and compete for substrate" -- 听起来有道理但生物学上不合理
- 选项 D："caused the directionality to change such that amino terminus became carboxy terminus" -- 用了专业术语但概念错误

#### 策略 6：Stimulus 数据的错误解读

**实例**（Q4 图表选择）：
- 选项 A（饼图）：用了数据但图形类型完全错误
- 选项 C（折线图）：把离散分组变量当连续变量画
- 选项 D（散点图）：画了 SE vs pH 这个无意义的关系
- 正确答案 B（柱状图+误差棒）：分类变量用柱状图，含误差棒

### 三、考点分布（按 Big Idea 统计）

| Big Idea | 核心考点 | 出现频率 |
|----------|--------|--------|
| **BI 1: Evolution** | 自然选择、Hardy-Weinberg、物种形成、进化证据（同源结构/DNA比较/化石）、内共生学说、遗传漂变、基因流、适应辐射 | 约 25% |
| **BI 2: Energetics** | 酶（活化能/抑制剂/pH温度效应）、光合作用、细胞呼吸、ATP偶联、跨膜运输（主动/被动/渗透） | 约 25% |
| **BI 3: Information** | DNA/RNA结构、复制、转录、翻译、基因调控、突变、生物技术（PCR/凝胶电泳）、遗传规律 | 约 25% |
| **BI 4: Interactions** | 细胞通讯（信号转导）、免疫、生态（种群增长/群落/生物多样性/生态系统破坏）| 约 25% |

**特别强调的交叉考点**：
- **结构-功能关系**（蛋白质折叠、膜结构、酶特异性）-- 几乎每 3 题就出现 1 次
- **实验设计**（控制组、自变量/因变量识别、误差棒统计判断）-- 横跨所有 Big Idea
- **进化思维应用**（在非进化主题中也考，如"为什么不同环境的蛋白质半胱氨酸含量不同"）

## 第二部分：FRQ（大题）深度分析

### 一、FRQ 的两种类型

#### 类型 1：长大题（Long Free Response, 8-10分，约25分钟）

**结构模板**：
```
背景段落（实验/情景描述，150-250词）
+ 数据展示（1-2个图/表）
+ (a) Describe/Explain（基础概念验证）
+ (b) Construct graph / Identify / Calculate（数据技能）
+ (c) Describe trend / Calculate / Determine（深层数据分析）
+ (d) Predict / Provide reasoning / Explain（综合推理与论证）
```

**典型示例**：
- Q10/11（Rubisco 实验）：4 parts，涉及蛋白质结构描述 -> 变量识别+数据比较+计算 -> 突变预测 -> 进化/遗传推理
- Q15（血红蛋白/镰刀细胞）：基因表达图+系谱图，跨越分子生物学、发育生物学、遗传学
- Q33（疟疾/抗药性）：药物IC50数据表，跨越进化、实验设计、数据分析

**核心特征**：
1. **一题覆盖 2-3 个 Unit** -- 不是单一知识点，而是跨主题整合
2. **Part 递进**：(a) 基础概念 -> (b) 数据技能 -> (c) 分析 -> (d) 高阶推理
3. **数据密度高**：通常含 1 个图 + 1 个表，或 2 个图

#### 类型 2：短大题（Short Free Response, 3-4分，约6分钟）

**结构模板**：
```
简短情景（1-3句）
+ 图/数据（通常1个）
+ (a) Connect / Describe（1分）
+ (b) Predict + Support/Justify（2分）
```

**典型示例**：
- Q12/13（酶动力学曲线）：Initial Rate vs [S] 的经典图 -> 连接一级结构与整体形状 -> 预测非竞争性抑制剂效果

### 二、FRQ 指令词（Verb）系统

CB 使用一套精确的指令词体系，**每个词对应不同的思维深度和评分标准**：

| 指令词 | 含义 | 思维深度 | 评分要求 |
|-------|------|--------|--------|
| **Identify** | 指出/命名 | 最低 | 写出正确名称即可 |
| **Describe** | 描述过程/模式 | 低-中 | 用完整句子陈述现象或过程 |
| **Construct** | 画图/建模 | 中（技能型） | 轴标签+刻度+正确绘图（3分） |
| **Calculate** | 计算 | 中 | 写出过程和数值 |
| **Determine** | 基于数据得出结论 | 中 | 引用具体数据支持结论 |
| **Explain** | 解释机制/因果 | 中-高 | 建立因果链条 |
| **Predict** | 预测结果 | 高 | 给出方向+机制 |
| **Justify** | 为预测/选择提供理由 | 高 | 用证据+原理支持 |
| **Provide reasoning** | 提供推理论证 | 最高 | 完整的 Claim-Evidence-Reasoning |
| **Connect** | 建立概念间联系 | 高 | 跨概念桥接 |

**出题者偏好模式**：通常在一道 FRQ 中**混用 3-4 种指令词**，形成递进结构。

### 三、实验设计题的固定模板

CB 反复使用以下**实验设计考查模式**：

#### 模式 A：控制组识别
给出一张实验设计表（多个试管/处理组），问"which serves as control and why?"

**实例**（Q5 Energy，淀粉酶pH实验）：8 个试管，变量包括 pH、有无淀粉、有无酶、是否煮沸。问 Test Tube V（煮沸处理的）为什么是控制组。

**评分要点**："shows color change in the ABSENCE of enzyme activity"（必须说明控制的是什么变量）

#### 模式 B：变量识别三件套
几乎每道长 FRQ 都会问：
1. Identify the **independent** variable
2. Identify the **dependent** variable  
3. Identify a condition that was **kept constant**

#### 模式 C：统计显著性判断
给数据含 +/- 2SE 或误差棒，问：
- "Determine whether there is a statistical difference between X and Y"
- **评分标准**：必须明确说"error bars overlap / do not overlap"

#### 模式 D：画图三要素
每当出现 **"construct an appropriately labeled graph"**，评分固定为 3 分：
1. 正确的轴标签（含单位）-- 1分
2. 正确的刻度和比例 -- 1分  
3. 正确绘制的数据点/柱/线 -- 1分

### 四、FRQ 评分模式

#### 评分哲学
1. **二元评分（0-1）为主**：每个 Part 的每个得分点通常是"给1分或0分"，不存在部分给分
2. **长大题 8-10 分**：由 4 parts x 每 part 1-3 个得分点组成
3. **短大题 4 分**：2 parts x 每 part 1-2 个得分点
4. **画图题独立 3 分**：轴标+刻度+正确绘图

#### 得分点设计规律
- **Describe 型得分点**：必须包含**过程**或**趋势方向**，只写结论不给分
- **Explain 型得分点**：必须有**因果连接词**（because, which leads to, resulting in）
- **Predict 型得分点**：必须给出**方向**（increase/decrease）+ **机制简述**
- **Justify/Reasoning 型得分点**：必须引用**题目提供的具体数据或信息**

#### 评分中的"必须"与"可接受"
- 评分指南会列出**精确表述**（"The response indicates that..."）
- 有时会标注多种可接受的表述方式
- **绝不**因拼写错误或语法问题扣分（只要意思正确）

## 第三部分：出题者的"元策略"

### 1. 结构-功能关系是第一原则
几乎所有生物分子题（蛋白质、核酸、脂质、碳水化合物）都围绕一个核心问题：**结构的改变如何导致功能的改变？** 这不是某个 Unit 的主题，而是贯穿整张试卷的思维框架。

### 2. 数据素养是隐形的第二主题
CB 不只是考生物学知识，更在考：
- 能否选择正确的图表类型（分类 -> 柱状图 vs 连续 -> 折线图）
- 能否通过误差棒判断统计显著性
- 能否区分相关性与因果性
- 能否识别自变量、因变量、控制变量

### 3. "预测+推理" 是最高分值的能力
在 FRQ 中，Predict + Justify/Provide reasoning 的得分点总是放在最后一个 Part（难度最高），也是区分 4 分和 5 分考生的关键。

### 4. 跨 Unit 整合是长大题的标志
**一道长 FRQ 至少跨越 2-3 个 Unit**。例如：
- Rubisco 题：Unit 1（蛋白质结构）+ Unit 3（细胞能量/光合）+ Unit 5（遗传/叶绿体遗传）
- 血红蛋白题：Unit 1（蛋白质）+ Unit 5（遗传）+ Unit 6（基因表达）+ Unit 7（进化/镰刀细胞贫血）

### 5. 干扰项的核心逻辑：用学生的"差一步推理"制造陷阱
CB 最厉害的干扰项不是乱写的，而是**学生推理到正确答案前一步时会停下来选的那个选项**。例如知道"突变影响蛋白质"但没想到"影响所有层级"，就会选只影响一级结构的选项。

## 第四部分：出题参数速查表（供 AI 出题使用）

### MCQ 参数

| 参数 | 规格 |
|-----|------|
| 选项数 | 4个（A-D），极少数旧题 5 个（A-E） |
| 题干长度 | 短题：2-4 句；长题（含实验）：8-15 句 + 图/表 |
| 共享 Stimulus | 2-4 道 MCQ 可共享同一个实验/数据描述 |
| 图/表占比 | 约 50-60% 的题含视觉 Stimulus |
| 否定型题干 | 极少使用（CB 几乎不用 "Which is NOT..."） |
| 计算型 MCQ | 约 5-8%（主要是 Hardy-Weinberg 和碱基配对比例） |

### FRQ 参数

| 参数 | 长大题 | 短大题 |
|-----|------|------|
| 总分 | 8-10 分 | 3-4 分 |
| Part 数 | 4 个 (a-d) | 2 个 (a-b) |
| 每 Part 得分点 | 1-3 | 1-2 |
| 时间 | ~25 分钟 | ~6 分钟 |
| Stimulus | 1-2 图 + 0-1 表 | 0-1 图 |
| 必含画图 | 约 60% 含 "construct graph" | 罕见 |
| 必含计算 | 约 50% 含 "calculate" | 罕见 |
| 跨 Unit | 2-3 个 Unit | 通常 1 个 Unit |

### 指令词使用频率

| 指令词 | FRQ 中出现频率 |
|-------|-------------|
| Describe | 最高（几乎每题都有） |
| Explain | 高 |
| Predict | 高 |
| Identify | 中 |
| Justify / Provide reasoning | 中 |
| Calculate | 中 |
| Construct (graph) | 中 |
| Connect | 低 |
| Determine | 低 |
