## 第一部分：MCQ（选择题）深度分析

### 一、题干结构分类

经统计，CB 的 MCQ 题干可归纳为 **6 种结构模板**，按出现频率排列：

| 结构类型 | 占比(估) | 典型引导词 |
|---------|---------|---------|
| **A. 图表/图片引入型** | ~35% | "Based on the graph/diagram/data..." |
| **B. 情景叙事引入型** | ~25% | 给出一段真实物种/生态系统描述，再提问 |
| **C. 直接概念提问型** | ~20% | "Which of the following..." 直接问概念 |
| **D. 匹配对应型（Stimulus Set）** | ~10% | 给出一组选项（A-E），多个题目共用同一组答案 |
| **E. 数据计算型** | ~5% | 给出数值要求计算（如 Rule of 70、增长率） |
| **F. 否定限定型** | ~5% | 使用 EXCEPT/NOT/LEAST |

#### A. 图表/图片引入型 -- 最核心的题型

**模板**：
```
[提供图表/图片/曲线/地图/年龄结构图]
Based on the [graph/diagram/data/map], which of the following...
```

**具体图表类型**：
- 种群增长曲线（S型 / J型 / 带超越K值的）
- 存活曲线（Type I / II / III，经常复用同一张图问2-3题）
- 捕食者-猎物双线图（如 Isle Royale 的狼-驼鹿）
- 年龄结构金字塔（识别人口增长阶段）
- 气候图（climatograph，温度+降水 = 判断生物群落）
- 食物网图（识别营养级、竞争关系、级联效应）
- 地图（世界地图标点，判断区域特征）
- CO2 浓度时间序列（Keeling Curve）
- 氮循环流程图

**出题者规律**：
1. 同一张图经常出 2-4 道连续题（称为 stimulus set），从简单的"读图"逐步递进到"推断原因"
2. 图表题的选项设计倾向于考察"最可能的解释"而非"唯一正确解释"
3. 年龄结构图和存活曲线是超高频视觉素材

#### B. 情景叙事引入型

**模板**：
```
[2-5句描述一个真实物种/生态事件/环境问题]
Based on this information / description, which of the following best [describes/explains/characterizes]...
```

**典型例子**：
- "The Chatham Island robin is a small endangered bird found in scrub forests... In 1980, the population decreased to only 5 individuals..."（问 population bottleneck）
- "The spotted lanternfly is a herbivorous insect... feeds on over 70 species of plants... reproduces once during its lifetime by laying between 30 and 50 eggs..."（问 r-selected + invasive）
- "Cycads are gymnosperms... long-lived with slow growth rates, show late reproductive maturity, and have very few offspring..."（问 K-strategist + Type I survivorship）

**出题者规律**：
1. 情景描述中**刻意嵌入多个概念线索**，要求学生综合判断
2. 描述中的数据（如"5 individuals""30-50 eggs"）往往是关键判断依据
3. 常考的是分类/命名能力：给描述 -> 判断属于什么策略/曲线/物种类型

#### C. 直接概念提问型

**模板**：
```
Which of the following [is true about / best describes / is generally true of]...
(A)-(E) 直接列概念
```

**例子**：
- "Members of an r-selected species characteristically..."
- "The K-selection reproductive strategy maximizes survival of offspring by producing..."
- "The crude growth rate, r, of a population is calculated by..."

#### D. 匹配对应型（Stimulus Set）

**模板**：
```
Directions: The following question(s) refer to the following [processes/relationships/biomes/countries].
(A) 选项A    (B) 选项B    (C) 选项C    (D) 选项D    (E) 选项E

Q1. [描述1] -> 选匹配项
Q2. [描述2] -> 选匹配项
Q3. [描述3] -> 选匹配项
```

**典型共享选项组**：
- 水质参数：Acidity / Turbidity / Hardness / Dissolved oxygen / Salinity
- 氮循环过程：Nitrification / Denitrification / Assimilation / Ammonification / Nitrogen fixation
- 种间关系：Commensalism / Parasitism / Mutualism / Predation / Competition
- 国家列表：Australia / Brazil / Chile / Russia / USA
- 生物群落：Temperate grassland / Taiga / Tropical rainforest / Tundra

**出题者规律**：同一组选项可以被复用（某些选项可能不用或用多次），这考的是**精确区分相似概念**的能力。

### 二、选项设计与干扰项分析

#### 干扰项设计的 7 大手法

| 手法 | 说明 | 实例 |
|-----|------|-----|
| **1. 概念相近混淆** | 用相近但不同的术语 | K-selected vs r-selected；Type I vs Type III |
| **2. 因果倒置** | 把结果写成原因 | "The large moose population led to increased predation" vs 正确的食物限制解释 |
| **3. 部分正确** | 选项前半句对但后半句错 | "The spotted lanternfly is a K-selected and invasive species"（K-selected 错，invasive 对）|
| **4. 真实但无关** | 陈述本身正确但不回答问题 | 问生物群落特征时，给一个正确但属于其他群落的特征 |
| **5. 过度泛化** | 把特例说成普遍规律 | "Primary succession always produces an abundance of nitrogen" |
| **6. 数量级错误** | 计算题中给接近但错误的数值 | carrying capacity 7,500 vs 干扰项 4,500 / 8,500 |
| **7. 组合型陷阱** | "I and II" / "II and III" 等组合 | 要求逐个验证每个子陈述的真假 |

#### 选项数量

- **旧版格式**（部分题目）：5 个选项 (A)-(E)
- **新版格式**（2020 redesign 后）：4 个选项 (A)-(D)
- 题库中两种并存，但趋势明显向 4 选项过渡

### 三、认知层次分布

| 层次 | 对应动词 | 占比(估) | 说明 |
|-----|---------|---------|-----|
| **记忆** | identify, define, state | ~15% | 匹配型题目（术语-定义配对） |
| **理解** | describe, explain, best describes | ~30% | 概念理解+区分相似术语 |
| **应用** | 给新情境 -> 应用已学概念分类 | ~35% | 最大占比，给真实物种/场景判断 |
| **分析** | 读图推断因果，evaluate claims | ~20% | 图表数据分析、多步推理 |

### 四、否定问法使用

- 使用频率：约 5-8% 的题目
- 典型措辞："LEAST likely"、"is NOT"
- 通常出现在**较简单的知识回忆题**中
- 否定词一律**大写加粗**以提醒学生

### 五、MCQ 可复用出题模板

**模板 1：图表解读三连击**
```
[提供一张数据图]
Q1: 基于图表的直接读数（记忆/理解）
Q2: 基于图表识别模式/策略（应用）
Q3: 基于图表推断原因/预测趋势（分析）
```

**模板 2：物种描述 -> 分类判断**
```
[3-5 句描述某物种的繁殖策略、寿命、后代数量等特征]
Which of the following best [describes/characterizes] this species?
选项组合：r/K-selected + Type I/II/III + invasive/endangered
```

**模板 3：匹配题组**
```
[给出 5 个术语/地名/过程]
Q1-Q3: 每题给一个描述，选择最匹配的术语
```

**模板 4：反直觉情景**
```
[描述一个看似矛盾或违反常识的现象]
Which of the following best explains this [paradox/observation]?
```

## 第二部分：FRQ（自由回答题）深度分析

### 一、FRQ 的两种核心格式

通过分析 frq-1 到 frq-5 的所有题目，CB 的 APES FRQ 存在两种截然不同的格式：

#### 格式 A：传统长题型（22 分钟/题，约 10 分）

**出现在**：frq-1 的 Q1（beetles/bees）、Q2（oil sands）、frq-3 的 Q4（biodiversity）

**结构**：
```
Directions: The suggested time for answering this question is about 22 minutes.

[一段长篇阅读材料/情景描述，100-200 词]

a. [子问题]
   i. [具体小问]
   ii. [具体小问]
b. [子问题]
c. [子问题]
d. [子问题]
```

**特征**：
- 包含 **阅读材料**（新闻文章、科学报告摘要）
- 子问题 3-4 个大项，每项可能再分 i/ii 小项
- 总分 10 分左右
- 涉及**多个知识领域**的综合运用
- 必有**计算题**

#### 格式 B：新版短题型（每题 1 分/part，共约 10 个 part）

**出现在**：frq-1 的 Q3-Q6、frq-3 的 Q1-Q3/Q5-Q7、frq-5 的 Q1-Q6

**结构**：
```
Write your answers in the spaces provided. Refer to the figure or diagram to answer the question.

[提供一张图/地图/食物网/生态系统图]

(a) Based on the [diagram/graph], describe...
(b) Based on the information in the [diagram], identify...
(c) [情景延伸] Identify... and explain...
(d) [概念应用] Identify the reproductive strategy of...

[新情景段落引入]
(e) Make a claim using evidence to...
(f) Make a claim based on evidence...

[又一个新情景段落]
(g) Identify the [dependent/independent] variable...
(h) Identify one variable... and explain...
(i) Describe the steps...
(j) Describe an anthropogenic occurrence...
```

**特征**：
- **10 个小问 (a)-(j)**，每个 1 分，共 10 分
- 基于同一个核心图/情景，但**逐步引入新情景段落**
- 前几个问基于图的，后几个问跳到新情景
- 每个 part 完全独立评分（得不到前面的分不影响后面）

### 二、FRQ 评分方式

#### 格式 A（传统长题）：Rubric-based，多分制

```
Part A: 3 points maximum
- 1 point; only the first answer is scored
- 2 points; 1 point for each activity. Only the first two answers are scored.

Part B: 4 points maximum
- 1 point for each identification and 1 point for each description
- The description must be LINKED to the identification
- Only the first two answers are scored
```

**核心评分规则**：
1. **"Only the first X answers are scored"** -- 只看前 N 个回答，多写无效
2. **"Must be LINKED"** -- 识别和描述必须对应配对
3. 计算题：1 分 setup + 1 分正确答案
4. 前一步错不影响后一步（如果用了错误数据但方法正确可得分）

#### 格式 B（新版短题）：Point-based，0 或 1

```
Part A: 0 | 1
The response describes the air temperature range for a boreal forest as the following:
- -5 C or -6 C to 3 C or 4 C

Part B: 0 | 1  
The response identifies the major grassland present within 20 degrees north and south of the equator as Savanna.
```

**核心评分规则**：
1. 每 part 只有 **0 分或 1 分**
2. 评分标准列出**所有可接受答案**
3. 各 part 完全独立，互不影响
4. 答案必须达到指定动词的要求精度

### 三、FRQ 动词层次体系（极其关键）

CB 使用的动词有严格定义，精度要求从低到高：

| 动词 | 要求 | 得分难度 | 出现频率 |
|-----|------|---------|---------|
| **Identify** | 只需给出名称/术语/选择，不需要解释 | 最简单 | 极高 |
| **Describe** | 需要给出特征/过程/现象的详细说明 | 中等 | 极高 |
| **Explain** | 需要给出因果关系/机制，说明"为什么" | 较难 | 高 |
| **Make a claim** | 需要明确立场 + 引用证据支持 | 较难 | 高（新题型标志） |
| **Justify** | 需要为已提出的方案提供理由 | 较难 | 中 |
| **Propose a solution** | 需要提出可行的解决方案 | 中等 | 中 |
| **Calculate** | 需要展示计算过程和最终答案 | 视题而定 | 中 |
| **Define** | 给出准确的概念定义 | 简单 | 低 |

**出题者规律**：动词在题目中一律**加粗**，这是对学生回答精度的明确指引。

### 四、FRQ 高频题型模板

#### 模板 1：食物网分析题（出现率极高）

```
[提供食物网图]
(a) Identify a primary producer / primary consumer / secondary consumer / tertiary consumer
(b) Describe what the arrows indicate (energy/matter flow)
(c) Describe the effect of removing/overharvesting species X
(d) Propose a strategy to increase population of species Y
```
**评分特点**：
- Identify 题只要说对名字就给分
- 描述题必须描述而非仅仅识别
- 提出策略题不接受"禁止所有捕捞"（too simplistic）

#### 模板 2：生物群落-气候图分析题（超高频复用）

```
[提供温度-降水散点图，标注各生物群落]
(a) Describe the temperature range for biome X
(b) Identify the grassland within latitude Y
(c) Explain why carbon cycling is slower in biome A than biome B
(d) Make a claim about biodiversity: biome X vs biome Y
(e) Explain an evolutionary adaptation on a remote island
(f-j) [跳转到新情景：能源、农业、实验设计等]
```
**注意**：这张图在 frq-1 Q3、frq-3 Q5、frq-5 Q1/Q6 中**反复出现**（同一张图出了至少 4 套不同的题），是 CB 最爱的 stimulus。

#### 模板 3：生态社区对比分析题（新版标志性题型）

```
[提供对比图：3 个森林的鹿种群密度与植物多样性]
(a) Describe the relationship between X and biodiversity in Community A
(b) Identify an indicator species
(c) Identify and explain: reintroduction of predators
(d) Identify reproductive strategy
(e) Make a claim: 评估某个管理方案
(f) Make a claim: 支持或反驳某个观点
(g-j) [跳转到新实验设计情景]
```
**出题者规律**：同一套 Forest A/B/C 图在 frq-1 Q6、frq-3 Q7、frq-5 Q3/Q4/Q5 中**以不同变体反复出现**，每次变更 (a)-(f) 的具体问法。

#### 模板 4：传统长题 -- 环境问题综合分析

```
[新闻文章/情景描述]
a. 解释原因（1-2小问）
b. 描述环境后果（要求 TWO，且必须配对"变化+影响"）
c. 描述经济后果（要求 TWO）
d. 识别一个生态系统服务 + 解释其益处
```

#### 模板 5：资源计算题

```
[给出提取率、储量等数值]
(a) Identify ecological benefit
(b) Identify economic benefit
(c) Describe TWO environmental consequences
(d) Calculate 天数 = 总储量 / 日提取率
(e) Calculate 年数 = 天数 / 365
(f) Calculate 年用水量 = 月产量 x 12 x 2
```
**评分特点**：
- 计算题 1 分给 setup（列式正确），1 分给答案
- 答案不需要单位
- 前一步算错可以用错误值继续算，后续步骤方法正确仍可得分

### 五、FRQ 常见陷阱

| 陷阱 | 说明 |
|-----|------|
| **动词不匹配** | 题目要 Describe 但只写了 Identify，不给分 |
| **多写惩罚** | "Only the first two answers are scored"，写 3 个如果第 1 个错就丢分 |
| **没有 LINK** | 要求配对的题（变化+影响），写了变化但没连接影响，不给分 |
| **过于笼统** | "Propose a solution" 不接受 "ban all harvesting" 这种极端方案 |
| **不引用证据** | "Make a claim" 必须基于图表/数据/题目信息中的证据 |

## 第三部分：总结性出题规律

### 1. 视觉材料是王道

CB 极其依赖图表、图片、地图、流程图。粗略统计：
- **MCQ**：约 40-50% 的题目包含视觉 stimulus
- **FRQ**：100% 的新版短题都基于图表/图片

### 2. 概念复用与变体

CB 有一个**有限的核心素材库**，同一张图/同一个情景在不同题目集中反复出现，但每次改变提问角度：
- 温度-降水生物群落图：至少出现 4 次
- 三森林鹿种群图：至少出现 5 个变体
- 存活曲线（Type I/II/III）：至少出现 4 次
- 年龄结构金字塔：至少出现 3 种不同国家

### 3. "Make a claim" 是新版 FRQ 的标志

2020 年 redesign 后，"Make a claim using evidence" 成为高频动词，几乎每套 FRQ 都有 2-3 个 claim 题。这要求学生：
1. 明确表态（同意/反对/支持/反驳）
2. 引用题目提供的具体证据
3. 逻辑连接态度与证据

### 4. 跨主题整合

一道 FRQ 通常横跨 2-3 个 Unit 的内容。典型搭配：
- 生物群落 + 碳循环 + 可再生能源
- 种群生态 + 人类影响 + 保护策略
- 食物网 + 物种入侵 + 实验设计

### 5. 实验设计是必考

几乎每套 FRQ 都有至少 2 个 part 涉及实验设计：
- Identify the dependent/independent variable
- Identify a variable that should be constant
- Describe the control group
- Identify the hypothesis
- Explain how modifying the experiment would alter results
