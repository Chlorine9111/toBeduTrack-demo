## 一、题库 UI 重设计（核心）

### 1.1 知识树侧边栏
- [ ] 页面加载后左侧显示 `KNOWLEDGE MAP`
- [ ] 显示「全部题目」+ 各知识簇节点，带题目计数
- [ ] 点击知识簇节点 → 右侧只显示该簇的题目
- [ ] 展开知识簇 → 显示子技能（subskill）节点
- [ ] 点击子技能 → 进一步筛选
- [ ] 再次点击已选中的节点 → 取消筛选回到上一级

### 1.2 紧凑行布局
- [ ] 每道题一行：类型 badge（选择/问答/填空）+ 难度点 + 题干预览 + 来源
- [ ] 一屏能看到 15-20 道题（对比旧版 3-5 道）
- [ ] 按知识簇 → 子技能分组，组头可折叠/展开

### 1.3 内联展开
- [ ] 点击题目行 → 下方展开详情（题干、选项、答案、解析、来源）
- [ ] MC 题正确选项绿色高亮
- [ ] 再次点击 → 收起详情
- [ ] 展开一道时点击另一道 → 自动切换

### 1.4 右键菜单
- [ ] 右键题目行 → 弹出菜单（复制题目 ID、删除题目）
- [ ] 点击「复制题目 ID」→ ID 写入剪贴板
- [ ] 点击「删除题目」→ 弹出确认 → 删除 → 题目从列表消失
- [ ] 点击菜单外区域 → 菜单关闭

### 1.5 多选模式
- [ ] 点击「多选」按钮 → 每行出现 checkbox
- [ ] 勾选题目 → 行变蓝，顶部显示「删除(N)」
- [ ] 批量删除 → 确认弹窗 → 删除成功 → 列表刷新
- [ ] 「退出多选」→ 恢复正常模式

### 1.6 筛选系统
- [ ] 搜索框输入 → 300ms 防抖后发起请求（不是每个按键都请求）
- [ ] 课程下拉 → 筛选对应课程
- [ ] 题型下拉 → MC/FR/fill_in 筛选
- [ ] 「更多」→ 展开单元、知识簇、考察方式、来源、状态筛选
- [ ] 筛选标签可单独清除或一键清除

### 1.7 资料 Tab
- [ ] 点击「资料」→ 切换到资料网格
- [ ] 卡片显示：类型、标题、摘要、识别/入库题数
- [ ] 多选删除功能正常

## 二、PDF 拖拽上传

### 2.1 上传入口
- [ ] 题目 Tab 顶部显示「上传 PDF 拆题」按钮
- [ ] 点击按钮 → 文件选择器（只接受 .pdf）
- [ ] 拖拽 PDF 到内容区 → 蓝色虚线覆盖层出现
- [ ] 松开 → 文件进入上传队列

### 2.2 上传队列
- [ ] 队列面板在底部显示，含状态图标 + 文件名 + 进度
- [ ] 等待中 → 空心圆 + "等待中..."
- [ ] 上传中/OCR/解析 → 旋转图标 + 进度条
- [ ] 完成 → 绿色勾 + "完成，N 道题已入库"
- [ ] 失败 → 红色叉 + 错误信息
- [ ] 「清除已完成」按钮正常工作
- [ ] 「+ 添加」按钮可追加文件
- [ ] 队列可收起/展开

### 2.3 点击查看结果
- [ ] 完成的文件名显示绿色下划线
- [ ] 点击 → 搜索栏自动填入文件名 → 列表显示该 PDF 的题目

### 2.4 断点恢复（重点反复测试）
- [ ] 上传一个 PDF，处理过程中**刷新页面**
- [ ] 刷新后队列面板应显示之前的上传记录
- [ ] pending/processing 状态的应**自动恢复轮询**
- [ ] 完成后题目正常出现在列表中
- [ ] 关闭浏览器 → 重新打开 → 24h 内的记录仍显示

### 2.5 多文件顺序处理
- [ ] 一次拖入 3 个 PDF → 队列显示 3 个任务
- [ ] 按顺序处理（第一个完成后才开始第二个）
- [ ] 每个完成后列表自动刷新
