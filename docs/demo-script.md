# Deskmate 宣传 Demo 视频脚本

## 项目定位

**Deskmate — 教师 AI 工作台**
一个平台完成教案、习题、评分标准、PBL 项目、试卷、判卷、排课、公众号编辑的完整教学工作流。

---

## 功能亮点与操作步骤

### 亮点 1：Agent 自主工作台（核心卖点）

**一句话**：告诉 AI 你要什么，它自动调工具、检索知识库、联网搜索，一次生成完整教学产物。

**操作步骤**：
1. 侧边栏点击「对话」进入 Agent 工作台
2. 输入：`帮我生成一份 AP Calculus Unit 3 的完整教案，附带 5 道配套选择题`
3. Agent 自动澄清缺失参数（弹出选择卡片）
4. 选择课程/难度后，Agent 开始执行：
   - 先检索私有知识库
   - 联网搜索最新考纲
   - 调用生成工具
5. 右侧 Canvas 实时展示生成的教案和习题
6. 点击标签页切换不同产物

**宣传话术**：`"不再在 ChatGPT、Google Docs、Excel 之间来回切换——一句话，所有教学材料一次生成。"`

---

### 亮点 2：智能判卷（上传 → OCR → AI 评分）

**一句话**：上传学生答卷 PDF，AI 自动识别答案并逐题评分，30 秒出成绩。

**操作步骤**：
1. 侧边栏点击「判卷」
2. 点击「新建判卷任务」→ 输入任务名
3. **设定答案键**：
   - 上传试卷 PDF → AI 自动推断正确答案（显示置信度）
   - 检查并修改低置信度的题
4. **上传学生答卷**：
   - 批量拖入学生 PDF 文件
5. 点击「自动判卷」
   - OCR 识别每道题的学生答案
   - AI 逐题评分 + 生成反馈
   - 标红「建议复核」的题目
6. 查看统计面板：
   - 班级平均分、分布图
   - 每题通过率
   - 薄弱知识点

**宣传话术**：`"一叠试卷拍照上传，AI 帮你改完还告诉你哪个知识点全班都没掌握。"`

---

### 亮点 3：Rubric 评分标准（生成 + 交互式编辑）

**一句话**：AI 生成 AP 官方风格评分标准，右侧表格直接拖拽编辑。

**操作步骤**：
1. 在 Agent 工作台输入：`帮我生成一个 AP Language 议论文写作的 Rubric`
2. 选择写作类型（议论文/分析论证/合成论文）
3. AI 生成包含多维度 + 多等级的评分标准
4. 右侧 Canvas 以**交互式表格**渲染：
   - 拖拽行调整维度顺序
   - 双击单元格编辑评分描述
   - 修改权重（自动归一化到 100%）
   - 点击 ✨ AI 改写某一维度
5. 点击「导出 PDF」下载正式评分表

**宣传话术**：`"不是给你一段文字让你自己排版——直接生成可编辑的评分表格，改完导出 PDF 就能用。"`

---

### 亮点 4：教案生成 + 公开发布

**一句话**：流式生成完整教案，可一键发布为公开链接分享给同事。

**操作步骤**：
1. 输入：`围绕 Related Rates 生成一份 45 分钟教案`
2. AI 流式输出教案结构：
   - 教学目标
   - 课堂导入（5 分钟）
   - 新课讲授（20 分钟）
   - 课堂练习（15 分钟）
   - 总结与作业（5 分钟）
3. 每个步骤可展开编辑：
   - 修改教师活动 / 学生活动
   - 调整时间分配
   - AI 改写某个步骤
4. 点击「发布」生成公开链接
5. 分享链接给同事 → 无需登录即可查看

**宣传话术**：`"45 分钟的课，3 分钟生成教案，改几下就能上课。"`

---

### 亮点 5：习题生成 + 题库管理

**一句话**：AI 生成题目自动入库，按知识点分类，下次直接检索复用。

**操作步骤**：
1. 输入：`生成 5 道 AP Chemistry 关于化学平衡的选择题，难度中等`
2. AI 生成 5 道题（含题干、选项、答案、解析）
3. 自动分类到知识点体系（化学平衡 → equilibrium_acid_base）
4. 点击「保存到题库」
5. 进入「题库」页面：
   - 左侧知识点树状导航
   - 按课程/题型/难度筛选
   - 搜索框语义搜索
6. 从题库选题 → 组卷 → 导出 PDF 试卷

**宣传话术**：`"生成的每道题自动归档到知识点树，下次出卷直接检索。"`

---

### 亮点 6：PBL 项目式学习设计

**一句话**：输入主题，AI 生成完整 PBL 方案，含驱动问题、阶段任务、评估方式。

**操作步骤**：
1. 输入：`设计一个关于校园碳排放的 PBL 项目`
2. AI 生成 3 个候选方案（A/B/C）：
   - 方案 A：校园碳足迹调查
   - 方案 B：绿色校园改造提案
   - 方案 C：碳中和模拟实验
3. 选择一个方案 → AI 展开完整细节：
   - 驱动问题
   - 项目阶段（4-6 周）
   - 每阶段任务 + 预期产出
   - 评估 Rubric
   - 材料清单
4. 可编辑每个字段 + AI 改写

**宣传话术**：`"PBL 不再是 Word 文档拼凑——结构化方案一键生成，三个备选随你挑。"`

---

### 亮点 7：微信公众号编辑器

**一句话**：教学内容一键转化为微信图文，复制粘贴就能发。

**操作步骤**：
1. 侧边栏点击「公众号编辑器」
2. 三栏布局：
   - 左栏：模板库 + 素材库
   - 中栏：手机画布预览（微信风格）
   - 右栏：属性面板
3. 选择模板 → 修改内容
4. 使用 AI 功能：
   - 输入关键词 → AI 生成完整文案
   - AI 自动排版（加标题、分割线、emoji）
5. 点击「复制到公众号」→ 粘贴到微信后台

**宣传话术**：`"教案出完了？顺手发个公众号推文吧——AI 帮你写好排好，复制就行。"`

---

### 亮点 8：排课系统

**一句话**：输入班级、教师、课程，模拟退火算法自动生成无冲突课表。

**操作步骤**：
1. 侧边栏点击「排课系统」
2. 设定基础参数：
   - 学校日程（周一到周五，每天 8 节课）
   - 添加班级、教师、课程
3. 设定约束：
   - 教师请假时段
   - 固定课程时段（如体育课只能下午）
4. 点击「生成课表」
5. 查看结果：
   - 逐班课表网格
   - 冲突统计（0 冲突 = 完美）
   - 可手动微调

**宣传话术**：`"排课不再是教务处的噩梦——AI 自动排好，零冲突。"`

---

### 亮点 9：内容库（一站式管理）

**一句话**：所有 AI 生成的教学内容自动入库，按类型/课程/知识点管理。

**操作步骤**：
1. 侧边栏点击「内容库」
2. 顶部标签切换：Rubric / 教案 / 题目 / PBL / 其他
3. 筛选条件：课程、单元、难度、状态
4. 网格/列表视图切换
5. 点击任意内容 → 查看详情 → 编辑 / 导出 / 删除
6. 批量选择 → 批量操作

**宣传话术**：`"生成过的每一份教案、每一道题、每一份 Rubric，都在这里等你。"`
