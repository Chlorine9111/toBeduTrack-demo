# Teacher Content Library MVP
状态: IN_PROGRESS

## 目标
把教师在 Agent 对话中生成的 Rubric、教案、习题等产物自动沉淀为可检索、可分类、可复用的内容库，减少教师回翻聊天记录的成本。

## 核心体验
- 教师只在对话里协作，生成成功后系统自动归档，无需手动保存。
- 内容库默认按内容类型浏览，再按课程与单元收拢，不以聊天时间线作为主视图。
- 打开内容条目时，看到的是与生成时一致的完整视图，而不是摘要卡片。
- 新对话可以直接引用内容库条目，作为改写、续写、复用的上下文输入。

## MVP 范围

### 1. 自动保存
- 触发时机：AI 生成物完整返回并成功渲染后自动入库；流式生成中途失败或中断不入库。
- 保存对象：首版覆盖 `Rubric`、`Lesson Plan`、`Questions/Exercises`、`Other`。
- 自动记录字段：
  - `contentType`
  - `title`
  - `course`
  - `unit`
  - `generatedAt`
  - `sourceConversationId`
  - `sourceMessageId`
  - `sourceItemId`（若为基于旧内容改写）
  - `contentPayload` 或结构化引用
- 元数据提取失败时，条目进入“未分类”，允许教师后续手动修正。

### 2. 浏览与信息架构
- 一级导航：按内容类型切分为 `Rubrics`、`Lesson Plans`、`Questions`、`Other`。
- 二级组织：进入类型后，按 `课程 -> 单元` 分组展示。
- 默认排序：组内按最近更新时间倒序。
- 列表最小信息集：
  - 标题
  - 课程 / 单元
  - 更新时间
  - 来源对话入口
  - 是否已重命名

### 3. 内容详情
- 详情页必须复用原始内容的展示组件或同一套 schema 渲染逻辑。
- 不做摘要模式替代完整详情。
- 详情页保留来源对话跳转，方便教师回看生成上下文。

### 4. 搜索与筛选
- `搜索` 纳入 MVP，不延期到 V2。
- MVP 搜索覆盖：
  - 标题
  - 教师备注
  - 课程名
  - 单元名
  - 内容摘要字段（若存储层已有可检索摘要）
- MVP 筛选维度：
  - 内容类型
  - 课程
  - 单元
  - 最近更新时间
- 默认排序支持：
  - 最近更新
  - 最近生成
- 首版不要求语义搜索或向量召回。

### 5. 批量操作
- `批量操作` 纳入 MVP，不延期到 V2。
- MVP 批量操作最小集合：
  - 多选条目
  - 批量删除（强确认）
  - 批量修正课程 / 单元归属
- 批量操作只作用于当前教师自己的内容，不跨教师空间。
- 批量删除执行前必须显示影响数量与二次确认。

### 6. 单条操作
- 引用到新对话：将完整条目作为上下文输入，而不是只传标题。
- 删除：带确认提示。
- 重命名：允许覆盖系统默认标题。
- 备注：允许教师补充识别信息，参与搜索。

## 明确规则
- “基于上一份内容修改”默认新建一条内容，并记录 `sourceItemId`，不直接覆盖原件。
- 来源对话删除策略暂不影响内容库保留，内容库条目仍作为独立资产存在。
- 首版不做回收站；删除即对教师视角不可见，是否物理删除由实现阶段再定。
- 首版不做跨教师共享。

## 非目标 / 延后到 V2
- 正文级全文搜索
- 语义搜索 / 向量召回
- 版本历史可视化
- 回收站与恢复
- 共享协作 / 团队空间
- 批量导出

## 实施建议
- 数据模型建议抽象为统一的 `content_library_items` 主表，避免 Rubric / Lesson Plan / Exercise 各自重复做列表聚合。
- 详情渲染继续复用领域已有 schema 与组件，内容库只负责索引、导航与引用编排。
- Agent 成功生成后，应由服务端完成入库，避免前端“看到但没存上”的状态不一致。

## 步骤
- [ ] 抽象统一的内容库数据模型与服务端入库入口，覆盖 Rubric、教案、习题和 Other。
- [ ] 在 Agent 生成成功链路中补自动归档，保证“可见结果”和“已落库状态”一致。
- [ ] 搭建内容库列表、筛选、批量操作与详情复用渲染。
- [ ] 补“引用到新对话”链路，让旧内容可以作为后续生成的上下文输入。
- [ ] 完成真实联调、数据核对与 UX 验证，确保不会出现“聊天里有，内容库里没有”。

## 完成标准
- 教师在 Agent 中生成的 Rubric / Lesson Plan / Questions 会自动出现在内容库。
- 内容库可按类型、课程、单元浏览，并能进入完整详情。
- 内容库支持关键词搜索与基础筛选。
- 内容库支持多选、批量删除、批量修正课程/单元。
- 新对话可引用已有内容条目继续加工。
