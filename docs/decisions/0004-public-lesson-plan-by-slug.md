# ADR-0004: 教案公开访问采用发布态 + slug 链接

## 状态
Accepted

## 背景
教师需要分享教案给外部查看者，但又不能暴露全部私有数据接口。

## 备选方案
1. 公开所有教案接口
2. 单独导出静态文件
3. 发布态 + slug 查询（当前实现）

## 决策
教案必须先发布，系统生成 `published_slug`，外部通过 `/lp/[slug]` 与 `/api/public/lesson-plans/[slug]` 访问。

## 决策理由
- 发布动作可显式控制可见性。
- 公开接口与教师私有接口天然分离。
- 与当前路由和数据结构完全匹配。

## 影响
- 正向影响：分享路径清晰，权限边界可控。
- 负向影响：需要维护发布/取消发布/归档状态机。
- 后续动作：在文档与检查中持续强调“未发布不可公开访问”。
